## 不可破坏的边界

1. `C/K/Q/EX/TH/KP/B/J` ID 不得随意重编号。
2. 题源信息、资料路线、独立推导、模型思考和未核实判断必须明确分栏。
3. 图形依赖题使用 `verified / route-only / ambiguous-scan` 等证据状态；参数看不清时不得猜测。
4. 不上传来源 PDF、扫描图、整套题面或第三方逐字答案。
5. 公式统一用 LaTeX；数值结论必须说明假设、量纲、误差容限和核验方式。
6. 控制器设计必须按需复核稳定性、稳态误差、时域、频域、控制量和实现约束。
