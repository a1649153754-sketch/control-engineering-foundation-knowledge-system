# 附录与速查

> 对应教材附录 A、附录 B 的学习入口。本页不是原书附录的复制，而是考试/练习所需的最小速查与使用边界。

## A1 · 常用拉普拉斯变换对

| 时域 | 复域 |
| --- | --- |
| $\delta(t)$ | $1$ |
| $1(t)$ | $1/s$ |
| $t$ | $1/s^2$ |
| $t^n$ | $n!/s^{n+1}$ |
| $e^{-at}$ | $1/(s+a)$ |
| $\sin\omega t$ | $\omega/(s^2+\omega^2)$ |
| $\cos\omega t$ | $s/(s^2+\omega^2)$ |
| $e^{-at}\sin\omega t$ | $\omega/[(s+a)^2+\omega^2]$ |
| $e^{-at}\cos\omega t$ | $(s+a)/[(s+a)^2+\omega^2]$ |

## A2 · 常用性质

- 线性：$\mathcal{L}\{af+bg\}=aF+bG$。
- 微分：$\mathcal{L}\{f'(t)\}=sF(s)-f(0^-)$。
- 积分：$\mathcal{L}\{\int_0^t f(\tau)d\tau\}=F(s)/s$。
- 时移：$\mathcal{L}\{f(t-a)1(t-a)\}=e^{-as}F(s)$。
- 频移：$\mathcal{L}\{e^{-at}f(t)\}=F(s+a)$。
- 卷积：$\mathcal{L}\{f*g\}=F(s)G(s)$。
- 初值定理：在相应条件下，$f(0^+)=\lim_{s\to\infty}sF(s)$。
- 终值定理：在相应稳定条件下，$f(\infty)=\lim_{s\to0}sF(s)$。

## A3 · 部分分式选择

1. 不同实极点：$\sum A_i/(s-p_i)$。
2. 重实极点：$A_1/(s-p)+A_2/(s-p)^2+\cdots$。
3. 共轭复极点：组合成实系数二次项，便于反演为衰减正弦。
4. 含延迟：先保留 $e^{-as}$，对其余有理部分反演后使用时移。

## B1 · 高阶系统的“最优模型”阅读框架

教材附录 B讨论高阶最优模型最佳频比的证明。复习时把它放入下面的设计语境：

- 通过合理配置闭环极点/特征频率，让高阶系统在快速性和超调之间取得折中；
- 频率比是极点层级与时间尺度分离的设计参数；
- 结论依赖模型结构和优化指标，不能脱离原书定义直接套到任意高阶系统；
- 使用前应回到教材附录确认“最优”的目标函数、模型形式和参数约束。

## B2 · 高阶设计的通用检查

- 主导极点是否真正主导：位置、留数、零点三者同时检查；
- 非主导极点是否足够快；
- 设计模型是否保持稳定与可实现；
- 参数摄动后性能是否仍可接受；
- 软件精确结果是否支持近似模型结论。

## A4 · 常用单位与换算

- 频率：$\omega=2\pi f$，$\omega$ 单位 rad/s，$f$ 单位 Hz。
- 分贝：$20\log_{10}A$ 用于幅值比；功率比常用 $10\log_{10}$。
- 相位：计算中可用 rad，读图常用 degree；转换时显式乘 $180/\pi$。
- 时间常数、采样周期、延迟必须使用统一时间单位。
