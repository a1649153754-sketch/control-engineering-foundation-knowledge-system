## 二、使用原则

1. **先做教材题，再查习题解。** 查解答前先写出母题 ID 和第一动作。
2. **查解答只查断点。** 标记自己卡在建模、结构、条件、运算还是验证，不把整页答案当作笔记。
3. **二稿必须脱离答案。** 合上习题解，用自己的符号和步骤重做。
4. **题号只用于定位。** 真正复习入口是节点 ID、母题 ID 和错误标签。
