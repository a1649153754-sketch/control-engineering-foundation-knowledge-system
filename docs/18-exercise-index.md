## 二、每道题如何挂接知识体系

每张卡使用稳定编号 `EX-C章-题号`，例如：

- `EX-C2-06`：习题 2-6，多环方块图化简；
- `EX-C4-06`：习题 4-6，由 Bode 渐近图反求传递函数；
- `EX-C8-09`：习题 8-9，用根轨迹同时满足稳态和动态指标；
- `EX-C10-12`：习题 10-12，多采样点结构的脉冲传递函数。

每道题都同时挂到：

```text
教材节点 Cx.y
→ 母题 Q-Cx-yy
→ 逐题解析 EX-Cx-yy
→ 错误标签
→ 3/7/14 天复测
```

## 三、解析卡的固定结构

1. **题意摘要**：用原创语言概括任务，不复刻题面；
2. **对应知识点**：列出稳定节点和母题；
3. **来源定位**：给出习题解印刷页和 PDF 页；
4. **解析路线**：按第一动作、推导顺序和校验顺序组织；
5. **关键公式**：使用 MathJax 渲染的 LaTeX；
6. **结果校验**：记录习题解中的关键数值、结构或图形特征；
7. **易错点**：指出最容易发生的模型、条件和运算错误；
8. **由本题补入知识库**：把局部解法抽象为可迁移结论。

## 四、使用原则

1. **先独立作答，再看解析。** 先写节点、母题和第一动作。
2. **解析只修断点。** 标记自己卡在 `MODEL / STRUCT / COND / ALG / INTERP / VERIFY` 哪一层。
3. **公式先看图鉴。** [LaTeX 公式图鉴](25-formula-atlas.md)用于读公式；[规则与公式卡](14-formula-cards.md)用于查条件。
4. **二稿必须脱离来源。** 合上习题解，用自己的符号重做，并用结果校验而不是逐行照抄。
5. **把题目反哺节点。** 反复出现的结论已整理到[习题反哺补充库](26-exercise-supplements.md)。
