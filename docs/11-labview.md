## C11.1 LabVIEW 介绍

**学习目标**：理解 LabVIEW 的虚拟仪器思想、前面板、程序框图和数据流执行方式。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目或实验要求说明 LabVIEW 控制仿真的组成、控件与连线逻辑。 |
| 主方法 | 区分前面板交互对象与程序框图数据流；按输入—算法—显示组织 VI，使用循环和结构控制执行。 |
| 核心关系 | LabVIEW 以数据可用性驱动节点执行，而不是按屏幕从左到右强制顺序。 |
| 失效边界 | 连线位置不等于执行先后；存在数据依赖时才形成顺序。 |
| 达标证据 | 能设计一个简单 VI 的前面板和程序框图框架。 |
