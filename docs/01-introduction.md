## 详细节点

## C1.1 控制理论在工程中的应用和发展

**学习目标**：建立控制工程的对象观：明确控制理论解决的是动态系统在给定目标、扰动和约束下的行为问题，并理解经典控制理论在工程中的发展脉络。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目要求说明控制工程研究对象、控制理论发展阶段，或比较经验调节与模型分析。 |
| 主方法 | 从“对象—输入—输出—扰动—目标—性能指标”六个要素描述工程问题，再判断需要建模、分析还是设计。 |
| 核心关系 | 控制任务可抽象为：在约束下使输出跟踪给定并抑制扰动，同时满足稳定性、准确性与快速性。 |
| 失效边界 | 控制理论并不等同于自动化设备清单；没有动态关系和性能目标，就还没有形成完整的控制问题。 |
| 达标证据 | 能用一个机械或机电对象写出六要素控制任务，并说明反馈为何有价值。 |
| 标签 | 概念 · 工程背景 · 系统观 |

## C1.2 自动控制系统的基本概念

**学习目标**：掌握自动控制系统、开环与闭环、反馈、比较元件、控制器、执行元件、被控对象和检测元件等基本概念。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 看到原理图、实物流程或文字描述，需要判断是否闭环、反馈符号及各环节作用。 |
| 主方法 | 先找被控量和给定量，再沿信号流确定比较点；若输出信息返回并影响控制作用，则为反馈系统。 |
| 核心关系 | 误差信号：$e(t)=r(t)-b(t)$；负反馈闭环传递函数：$\Phi(s)=\dfrac{G(s)}{1+G(s)H(s)}$。 |
| 失效边界 | “有传感器”不必然构成闭环；必须确认检测信号确实返回比较并改变控制输入。反馈也不天然保证稳定。 |
| 达标证据 | 能把任一控制系统画成规范功能方块图，标出信号方向与反馈极性。 |
| 标签 | 开环 · 闭环 · 反馈 · 组成 |

## C1.3 控制理论在机械制造工业中的应用

**学习目标**：理解伺服、随动、数控机床、机器人、柔性制造等机械制造场景中的控制结构与性能诉求。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给出机床、机器人、转速或位置控制对象，要求识别控制变量、反馈变量和主要扰动。 |
| 主方法 | 将机械过程分成动力源、传动链、负载、检测与控制五部分；把加工精度、响应速度和抗扰能力映射到控制指标。 |
| 核心关系 | 典型机电伺服链：电信号 → 功率放大 → 执行电机 → 机械传动 → 位移/速度输出 → 检测反馈。 |
| 失效边界 | 不要把机械结构误差全部归因于控制器；间隙、摩擦、刚度和传感器分辨率也会形成性能上限。 |
| 达标证据 | 能针对一个机械制造实例说明控制回路、扰动来源和至少三项性能指标。 |
| 标签 | 机械制造 · 伺服 · 工程应用 |
