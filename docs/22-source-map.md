# 来源、页码与版本边界

> 本项目以《控制工程基础（第4版）》为主线，以《控制工程基础习题解（第4版）》为题型与解题过程参照。页码同时记录原书印刷页和当前 PDF 页，便于定位。

## 一、来源书目

- **教材**：《控制工程基础（第4版）》，董景新、赵长德、郭美凤、陈志勇、刘云锋、李冬梅编著，清华大学出版社。

## 五、范围差异

1. 配套习题解目录覆盖第 1—10 章；教材第 11 章 LabVIEW 演示软件没有单独的题解章节。
2. 教材中的软件界面与命令以出版时版本为背景。本项目保留其分析任务和术语，不承诺当前软件界面完全相同。
3. 项目中的“母题、规则卡、边界卡”是原创抽象，不代表原书官方分类。
4. 若本项目公式符号与某道原题不一致，应以该题原书定义为准。
