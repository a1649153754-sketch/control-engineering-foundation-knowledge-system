## C8.1 根轨迹与根轨迹方程

**学习目标**：理解根轨迹是闭环特征根随参数变化的轨迹，并掌握幅值条件和相角条件。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 开环增益或其他参数变化，要求闭环极点轨迹、稳定范围或指定极点所需参数。 |
| 主方法 | 由 $1+KG_0(s)H(s)=0$ 写根轨迹方程；先用相角条件判点，再用幅值条件求参数。 |
| 核心关系 | $\angle G_0(s)H(s)=(2k+1)180^\circ$；$K=1/\lvert G_0(s)H(s)\rvert$（标准负反馈）。 |
| 失效边界 | 相角条件依赖标准根轨迹参数形式；参数不在纯增益位置时应先等效整理。 |
| 达标证据 | 能判断复平面一点是否在轨迹上并求对应增益。 |
| 标签 | 根轨迹方程 · 相角条件 · 幅值条件 |

## C8.2 绘制根轨迹的基本法则

**学习目标**：掌握实轴段、起终点、渐近线、分离/会合点、出射/入射角、虚轴交点等绘图法则。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 要求手绘根轨迹并标关键参数。 |
| 主方法 | 按固定清单逐项：极零点 → 实轴段 → 分支数 → 渐近线 → 分离点 → 角度 → 虚轴交点 → 方向与对称。 |
| 核心关系 | 渐近线交点 $\sigma_a=(\sum p_i-\sum z_i)/(n-m)$；角度 $\theta_k=(2k+1)180^\circ/(n-m)$。 |
| 失效边界 | 分离点方程的全部根不一定都在根轨迹上；必须回代实轴段/相角条件筛选。 |
| 达标证据 | 能手绘一个三阶以上系统轨迹并标注关键增益。 |
| 标签 | 绘图法则 · 渐近线 · 分离点 |

## C8.3 其他参数根轨迹图的绘制

**学习目标**：掌握参数不作为纯开环增益时的广义/其他参数根轨迹构造。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 特征方程中变化参数出现在多个系数，题目要求随该参数的根轨迹。 |
| 主方法 | 把特征方程整理为 $A(s)+\lambda B(s)=0$，写成 $1+\lambda B(s)/A(s)=0$，再按标准法则绘制。 |
| 核心关系 | $1+\lambda G_\lambda(s)=0$，其中 $G_\lambda(s)=B(s)/A(s)$。 |
| 失效边界 | 整理时不能把含参数的公共因子遗漏；参数符号区间不同可能对应正/负根轨迹。 |
| 达标证据 | 能把一个阻尼或反馈系数问题转成参数根轨迹。 |
| 标签 | 参数根轨迹 · 广义根轨迹 · 特征方程 |

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给指标线或指定极点区域，要求从图上选参数。 |
| 主方法 | 在根轨迹上叠加等阻尼线、等自然频率圆或实部限制线，找交点，再用幅值条件求参数。 |
| 核心关系 | 等阻尼线由极点与负实轴夹角确定；$\zeta=-\sigma/\sqrt{\sigma^2+\omega^2}$。 |

| 达标证据 | 能从根轨迹选择参数并用闭环仿真验证。 |

## C8.5 系统闭环零点、极点的分布与性能指标

**学习目标**：理解闭环零极点分布、留数和主导极点对时域性能的共同作用。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 根轨迹给出闭环极点，但题目追问超调、速度或零点影响。 |
| 主方法 | 先识别主导极点，再看闭环零点是否接近主导极点以及其他极点是否足够远；必要时部分分式估计留数。 |
| 核心关系 | 闭环响应取决于极点位置和模态系数；零点可显著改变超调和初始形状。 |
| 失效边界 | 近似零极点相消只在参数精确且内部模态安全时成立；靠近主导极点的零点通常不能忽略。 |
| 达标证据 | 能解释同一主导极点但不同零点系统为何响应不同。 |
| 标签 | 闭环零极点 · 留数 · 主导极点 |
