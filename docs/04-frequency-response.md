## C4.1 机电系统频率特性的概念及其基本实验方法

**学习目标**：理解频率响应的物理意义：稳定线性系统对正弦输入的稳态输出仍为同频正弦，仅幅值与相位改变，并掌握基本实验测量。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给出正弦输入、稳态输出或实验装置，要求求幅频/相频或解释频率扫描。 |
| 主方法 | 令 $s=j\omega$ 得频率响应；由输出输入幅值比求 $A(\omega)$，由相位差求 $\varphi(\omega)$，扫描频率形成特性曲线。 |
| 核心关系 | $G(j\omega)=A(\omega)e^{j\varphi(\omega)}$；$A=Y_m/X_m$，$\varphi=\varphi_y-\varphi_x$。 |
| 失效边界 | 频率响应建立在零状态、线性、稳定和稳态正弦响应基础上；瞬态尚未衰减时测得的相位不可靠。 |
| 达标证据 | 能由时域正弦曲线计算一个频点的幅值比和相位差，并说明实验条件。 |
| 标签 | 频率响应 · 正弦稳态 · 实验 |
