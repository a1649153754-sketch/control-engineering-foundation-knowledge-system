# 任务决策树

> 共 16 条。用于考试或工程分析的“第一步选择”，避免把所有题都拖进同一种算法。

## D-01 从物理系统到数学模型

**适用范围**：C2

```text
├─ 1. 明确输入、输出、扰动、正方向和单位
├─ 2. 按元件分解，写局部物理定律
├─ 3. 选择微分方程、传递函数或状态空间目标表示
├─ 4. 消去中间变量并检查量纲、静态极限和符号
└─ 5. 用极点、直流增益或仿真做最小验证
```

## D-02 复杂方块图/信号流图化简

**适用范围**：C2

```text
├─ 1. 先标出目标输入与目标输出
├─ 2. 若存在明显内环，优先逐层闭环化简
├─ 3. 若交叉支路妨碍化简，谨慎移动比较点/引出点
├─ 4. 仍复杂时转信号流图，列前向通路和互不接触回路
└─ 5. 用梅逊公式并以极限/简化情形复核
```

## D-03 时域响应计算方法选择

**适用范围**：C3

```text
├─ 1. 识别输入类型与初始条件
├─ 2. 一阶/标准二阶优先调用标准响应
├─ 3. 有理高阶系统用部分分式和主导极点
├─ 4. 分段/延迟输入使用移位定理
└─ 5. 最后检查初值、终值、稳定性和单位
```

## D-04 二阶性能指标反求

**适用范围**：C3

```text
├─ 1. 确认标准欠阻尼二阶近似成立
├─ 2. 由超调量先求阻尼比 ζ
├─ 3. 由峰值/调整/上升时间求 ωn 或 ωd
├─ 4. 写目标特征多项式或极点区域
└─ 5. 检查零点和非主导极点是否破坏近似
```

## D-05 Bode 图手绘与反求

**适用范围**：C4

```text
├─ 1. 标准化传递函数并列出 K、积分阶次、转折频率
├─ 2. 从低频截距和斜率起笔
├─ 3. 逐个转折点累计幅值斜率
├─ 4. 叠加各环节相位并校核极限
└─ 5. 反求时用幅值提出候选结构，再用相位排除歧义
```

## D-06 稳定性判据选择

**适用范围**：C5

```text
├─ 1. 低阶可直接求根/看极点
├─ 2. 高阶多项式参数范围优先 Routh
├─ 3. 已知完整频率轨迹或含开环不稳定极点用 Nyquist
├─ 4. 已知 Bode 图且系统条件典型可读裕度
└─ 5. 含延迟先利用其幅值不变、相位线性滞后特点
```

## D-07 Routh 特殊情况处理

**适用范围**：C5

```text
├─ 1. 按降幂完整写系数，缺项补零
├─ 2. 普通情形计算首列并看符号变化
├─ 3. 首列首项为零但该行不全零：用 ε 或等价变换
├─ 4. 整行全零：取上一行辅助多项式求导替换
└─ 5. 参数题把所有必要不等式取交集并验证边界
```

## D-08 Nyquist 稳定判断

**适用范围**：C5

```text
├─ 1. 确定开环右半平面极点数 P
├─ 2. 构造完整 Nyquist 轮廓并处理虚轴极点
├─ 3. 标频率方向和共轭对称部分
├─ 4. 按统一符号约定统计对 -1 点的环绕数
└─ 5. 求闭环右半平面极点数并判断临界情况
```

## D-09 稳态误差计算

**适用范围**：C6

```text
├─ 1. 先明确物理误差和反馈是否单位
├─ 2. 检查闭环稳定性
├─ 3. 写误差传递函数 E/R 或 E/N
├─ 4. 典型输入可用型别与误差系数，其他输入用终值定理
└─ 5. 扰动问题按注入点单独推导，最后检查极限条件
```

## D-10 频率法校正设计

**适用范围**：C7

```text
├─ 1. 把时域/误差指标换算为 ζ、ωc、低频增益和裕度
├─ 2. 画对象 Bode，诊断低中高频主要不足
├─ 3. 选择超前、滞后、滞后超前或反馈结构
├─ 4. 计算零极点和增益，并预留相位余量
└─ 5. 校正后重新求交叉频率，检查时域、误差、裕度和高频噪声
```

## D-11 PID 结构选择

**适用范围**：C7

```text
├─ 1. 若只有比例可满足且误差允许，先用 P
├─ 2. 需要消除低阶稳态误差时考虑 PI
├─ 3. 需要增加阻尼/预测作用且噪声允许时考虑 PD
├─ 4. 精度与动态都不足可用 PID
└─ 5. 实际实现加入微分滤波、积分抗饱和并重新验证
```

## D-12 根轨迹设计

**适用范围**：C8

```text
├─ 1. 写成标准参数根轨迹方程
├─ 2. 按基本法则手绘关键结构
├─ 3. 叠加等阻尼线、等自然频率圆或稳定边界
├─ 4. 由相角条件确认目标点，由幅值条件求参数
└─ 5. 检查其他闭环极点、零点和实际响应
```

## D-13 非线性分析方法选择

**适用范围**：C9

```text
├─ 1. 关注小范围平衡点：先局部线性化
├─ 2. 关注近正弦自振：使用描述函数与谐波平衡
├─ 3. 二阶自治系统且关注全局轨迹：使用相平面
├─ 4. 需要不求解方程证明稳定：尝试 Lyapunov
└─ 5. 所有解析结论用多初值数值仿真作补充而非替代证明
```

## D-14 离散系统分析

**适用范围**：C10

```text
├─ 1. 明确采样周期、保持器和序列定义
├─ 2. 建立差分方程、脉冲传递函数或离散状态模型
├─ 3. 求单位圆内极点/Jury 稳定条件
├─ 4. 用 Z 变换求响应和稳态误差
└─ 5. 比较不同采样周期与离散化方法的性能和实现代价
```

## D-15 连续控制器数字化

**适用范围**：C10

```text
├─ 1. 完成连续域控制器设计并确认带宽
├─ 2. 选择采样周期，通常需明显快于闭环主要动态
├─ 3. 选择双线性、差分或零极点匹配方法
├─ 4. 化为递推式并考虑计算延迟、饱和和量化
└─ 5. 连续/离散联合仿真验证稳定、响应和控制量
```

## D-16 软件/实验结果可信性检查

**适用范围**：C3/C4/C7/C10/C11

```text
├─ 1. 先做理论先验：极点、终值、斜率、稳定性
├─ 2. 显式设置时间/频率/采样范围和单位
├─ 3. 用至少一个已知基准模型校准
├─ 4. 改变步长、频率网格或求解器检查数值收敛
└─ 5. 保存参数、代码/VI 版本和结果表，保证可复现
```
