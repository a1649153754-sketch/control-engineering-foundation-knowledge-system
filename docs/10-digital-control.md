## C10.2 线性离散系统的数学模型

**学习目标**：掌握差分方程、Z 变换、脉冲传递函数和离散状态空间模型。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给差分方程或采样系统，要求求 Z 变换、脉冲响应或离散模型。 |
| 主方法 | 按单边/双边约定取 Z 变换并处理初值；有零阶保持器时先求等效离散对象；写成 $G(z)$ 或状态方程。 |
| 核心关系 | $X(z)=\sum_{k=0}^{\infty}x(kT)z^{-k}$；离散状态：$x_{k+1}=A_dx_k+B_du_k$。 |
| 失效边界 | Z 变换定义、初值约定和采样时刻必须一致；连续传递函数不能不经离散化直接当作 $G(z)$。 |
| 达标证据 | 能在差分方程、脉冲传递函数和离散状态空间间转换。 |
| 标签 | Z变换 · 差分方程 · 离散模型 |

## C10.3 线性离散系统的性能分析

**学习目标**：掌握离散系统稳定性、稳态误差和动态响应分析，理解 z 平面与 s 平面映射。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目要求判断单位圆稳定、用 Jury 判据、求离散终值或响应。 |
| 主方法 | 先求闭环特征多项式；检查极点是否在单位圆内，或用 Jury 表；用 Z 反变换/终值定理求响应与误差。 |
| 核心关系 | 离散渐近稳定：$\lvert z_i\rvert<1$；映射 $z=e^{sT}$ 将左半 $s$ 平面映到单位圆内。 |
| 失效边界 | 单位圆上的单根通常意味着临界稳定；离散终值定理同样要求相应极点条件。 |
| 达标证据 | 能在 z 平面画极点并解释采样周期变化的映射影响。 |
| 标签 | 离散稳定 · Jury判据 · 单位圆 |

## C10.4 计算机控制系统的模拟化设计方法

**学习目标**：理解连续域控制器模拟化设计：先按连续方法设计，再选离散化方法实现并评估误差。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给连续控制器或性能指标，要求数字实现、差分方程或采样周期。 |
| 主方法 | 先完成连续设计；选前向/后向差分、双线性变换或零极点匹配；得到 $D(z)$，化为递推算法并检查频率畸变。 |
| 核心关系 | 双线性变换：$s=\dfrac{2}{T}\dfrac{z-1}{z+1}$；必要时使用预畸变。 |
| 失效边界 | 模拟化设计依赖采样足够快；不同离散化方法在稳定性、相位和高频特性上不同。 |
| 达标证据 | 能把一个 PI/PID 连续控制器离散化并写成可执行差分方程。 |
