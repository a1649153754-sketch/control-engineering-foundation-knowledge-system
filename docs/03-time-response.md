## C3.1 时域响应以及典型输入信号

**学习目标**：掌握时域响应、稳态分量、瞬态分量及阶跃、斜坡、加速度、脉冲和正弦等典型输入。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目要求选择测试输入、写输入拉氏变换或说明输入对系统性能的激励作用。 |
| 主方法 | 先判断被测性能：跟踪、冲击、速度或频率响应；再写标准输入及其变换，最后与系统传递函数相乘。 |
| 核心关系 | 单位阶跃 $1(t)\leftrightarrow 1/s$；斜坡 $t\leftrightarrow 1/s^2$；脉冲 $\delta(t)\leftrightarrow 1$。 |
| 失效边界 | 输入类型必须与幅值、作用时刻和单位一致；单位脉冲是理想模型，实际实验只能近似实现。 |
| 达标证据 | 能为不同测试目的选择输入，并写出输出变换表达式。 |

## C3.2 一阶系统的瞬态响应

**学习目标**：熟练分析一阶系统对阶跃、斜坡和脉冲输入的响应及时间常数意义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 系统可化为 $K/(Ts+1)$，要求求响应、时间常数、上升速度或由曲线识别参数。 |
| 主方法 | 先写标准形式，利用标准响应或部分分式反演；从 63.2% 点、初始斜率或稳态值识别 $T$ 与 $K$。 |
| 核心关系 | 单位阶跃响应：$y(t)=K(1-e^{-t/T})$；脉冲响应：$g(t)=\dfrac{K}{T}e^{-t/T}$。 |
| 失效边界 | 时间常数不是“达到稳态的时间”；它描述指数衰减尺度，工程稳态常用 $3T$、$4T$ 或 $5T$ 近似。 |
| 达标证据 | 能由传递函数画响应草图，也能由响应曲线反求 $K,T$。 |
| 标签 | 一阶系统 · 时间常数 · 标准响应 |

## C3.3 二阶系统的瞬态响应

**学习目标**：掌握二阶系统按阻尼比分类的瞬态响应，理解自然频率、阻尼比、阻尼振荡频率与极点位置。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 分母为二次式，题目要求响应形式、是否振荡、参数变化趋势或标准化。 |
| 主方法 | 配方到标准二阶形式，求 $\omega_n,\zeta$ 与极点；按欠阻尼、临界、过阻尼、无阻尼、负阻尼分类。 |
| 核心关系 | $s^2+2\zeta\omega_ns+\omega_n^2$；欠阻尼极点 $-\zeta\omega_n\pm j\omega_n\sqrt{1-\zeta^2}$。 |
| 失效边界 | 只看二次项系数不能直接判断性能；必须先保证标准化且考虑分子零点和附加极点影响。 |
| 达标证据 | 能从任意二阶分母提取参数，并画出极点与响应特征对应图。 |
| 标签 | 二阶系统 · 阻尼比 · 自然频率 |

## C3.4 时域分析性能指标

**学习目标**：掌握上升时间、峰值时间、最大超调量、调整时间和振荡次数等时域指标及其适用条件。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给出二阶系统参数或响应曲线，要求计算指标、反求参数或比较快慢与平稳性。 |
| 主方法 | 先确认是标准欠阻尼二阶系统；再由 $\zeta$ 求超调、由 $\omega_d$ 求峰值时间、由包络近似求调整时间。 |
| 核心关系 | $M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}$；$t_p=\pi/\omega_d$；$t_s\approx 3/(\zeta\omega_n)$（5%带）或 $4/(\zeta\omega_n)$（2%带）。 |
| 失效边界 | 指标公式依赖标准二阶、单位阶跃和指定误差带；有零点、高阶极点或非单位稳态值时需重新判断。 |
| 达标证据 | 能由指标反算 $\zeta,\omega_n$，并明确采用的误差带。 |
| 标签 | 性能指标 · 超调量 · 调整时间 |

## C3.5 高阶系统的瞬态响应

**学习目标**：理解高阶系统响应由各极点模态叠加，掌握主导极点、非主导极点和零点影响。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 系统阶数较高，要求估算响应、判断能否降阶或说明附加零极点影响。 |
| 主方法 | 部分分式展开识别各模态；比较极点实部和留数，选出对关注时间尺度贡献最大的主导模态。 |
| 核心关系 | $y(t)=\sum_i A_i e^{p_i t}$（含共轭复极点时组合为衰减正弦项）。 |
| 失效边界 | “最靠近虚轴”是主导极点的常用必要线索，但留数很小、近零点相消或输入输出通道改变时可能失效。 |
| 达标证据 | 能对一个三阶或四阶系统说明主导模态并给出降阶合理性检查。 |
| 标签 | 高阶系统 · 主导极点 · 降阶 |

| 题目信号 | 题目要求设计阶跃/脉冲实验，或根据实验曲线辨识一阶、二阶参数。 |
| 主方法 | 确定输入发生器、测量链、采样速度与安全幅值；做基线校准，记录输入和输出，再由曲线特征辨识参数。 |
