## EX-C7-01｜习题 7-1：校正前后 Bode 图与裕度比较 { #ex-c7-01 }

**题意摘要**

比较原系统与串联一阶校正后系统的截止频率、相角裕度和动态趋势。

**对应知识点**

`C7.1`、`C7.2`；母题 `Q-C7-07`。

**来源定位**

习题解印刷页 92–93（PDF p.98–99）。

### 解析路线

1. 叠加校正器幅相贡献。
2. 重新确定交叉频率。
3. 在新交叉频率读取相位并比较速度/稳定裕度。

### 结果校验

习题解指出校正后截止频率提高、相角裕度增大。

### 易错点

- 仍在原交叉频率评价校正后相角裕度。

!!! tip "由本题补入知识库"
    补充：校正器改变幅值会移动交叉频率，缺相量不能只在原频率计算。

## EX-C7-02｜习题 7-2：PI 校正对低频精度与稳定性的影响 { #ex-c7-02 }

**题意摘要**

分析比例—积分校正对低频增益、型别、交叉频率和相角裕度的影响。

**对应知识点**

`C7.3`；母题 `Q-C7-03`。

**来源定位**

习题解印刷页 93（PDF p.99）。

### 解析路线

1. 写 PI 因子 $(Ts+1)/(Ts)$。
2. 观察原点新增极点与低频增益提升。
3. 叠加相位滞后并重新评价交叉频率。

### 结果校验

习题解显示速度误差改善，但相角裕度减小、代价是稳定性变差。

### 易错点

- 只强调积分消除误差而忽略相位滞后。

!!! tip "由本题补入知识库"
    补充：PI 的积分零点应放在足够低频，以减小对交叉频率附近相位的破坏。

## EX-C7-03｜习题 7-3：串联校正的 Bode 设计与稳定复核 { #ex-c7-03 }

**题意摘要**

对给定高阶对象叠加一阶校正器，画前后 Bode 图并判断系统是否稳定。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 93–94（PDF p.99–100）。

### 解析路线

1. 重建未校正 Bode 图和基线裕度。
2. 叠加校正器零极点贡献。
3. 求新交叉频率和相角裕度，最后判断稳定。

### 结果校验

习题解给出校正前约 $\omega_c=45$、裕度很小，校正后约 $\omega_c=5$、相角裕度约 $54.5^\circ$。

### 易错点

- 只看校正器提供正相位，不考虑它降低交叉频率。

!!! tip "由本题补入知识库"
    补充：有些“校正”主要通过移动交叉频率，而非单纯增加相位。

## EX-C7-04｜习题 7-4：按谐振峰和相角裕度选择增益 { #ex-c7-04 }

**题意摘要**

对给定单位反馈系统选择增益，同时满足闭环谐振峰和相角裕度要求，并估计超调与调整时间。

**对应知识点**

`C7.1`、`C7.5`；母题 `Q-C7-01`。

**来源定位**

习题解印刷页 94–95（PDF p.100–101）。

### 解析路线

1. 由 $M_r$ 约束换算为阻尼/相角裕度近似。
2. 在开环相位曲线上选择交叉频率。
3. 由幅值条件求 $K$，再用二阶近似估计时域指标。

### 结果校验

习题解得到 $K$ 不超过约 9.2，并给出 $M_p,t_s$ 的估计。

### 易错点

- 把闭环谐振峰直接等于开环峰值。

!!! tip "由本题补入知识库"
    补充：频域到时域换算依赖二阶主导近似，应标明近似性质。

## EX-C7-05｜习题 7-5：加速度反馈校正设计 { #ex-c7-05 }

**题意摘要**

为伺服系统设计加速度反馈，使超调与速度误差系数达到要求。

**对应知识点**

`C7.4`；母题 `Q-C7-05`。

**来源定位**

习题解印刷页 95（PDF p.101）。

### 解析路线

1. 先化简加速度内反馈后的等效对象。
2. 用稳态指标确定前向增益。
3. 用阻尼/超调指标确定加速度反馈系数。

### 结果校验

习题解通过增加一个与 $s^2$ 相关的反馈环节提高等效阻尼。

### 易错点

- 在未化简内环前直接套外环二阶公式。

!!! tip "由本题补入知识库"
    补充：高阶导数反馈提高阻尼/带宽的同时会放大高频噪声。

## EX-C7-06｜习题 7-6：保持瞬态指标的滞后校正 { #ex-c7-06 }

**题意摘要**

在基本保持交叉频率与相角裕度的前提下，提高速度误差系数。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-03`。

**来源定位**

习题解印刷页 95–96（PDF p.101–102）。

### 解析路线

1. 由稳态精度要求求低频增益提升倍数。
2. 把滞后零极点放在新交叉频率以下一至两数量级。
3. 调增益使交叉频率近似保持不变并复核裕度。

### 结果校验

习题解给出一个低频零极点很接近、增益提升约 10 倍的滞后网络。

### 易错点

- 滞后零极点放得太接近交叉频率，造成额外相位损失。

!!! tip "由本题补入知识库"
    补充：滞后校正的核心是“低频增益提升、中频增益近似不变”。

## EX-C7-07｜习题 7-7：满足 $K_v$、截止频率和相角裕度的滞后设计 { #ex-c7-07 }

**题意摘要**

对 $1/[s(s+1)]$ 设计滞后网络，同时满足速度误差系数、交叉频率和相角裕度下限。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-03`。

**来源定位**

习题解印刷页 96–97（PDF p.102–103）。

### 解析路线

1. 由 $K_v$ 求总低频增益。
2. 由目标相角裕度选交叉频率。
3. 求衰减比并布置滞后零极点，最后调整增益。

### 结果校验

习题解得到一组 $h\approx4$、低频增益约 15 的参数。

### 易错点

- 先固定零极点后才检查相角裕度。

!!! tip "由本题补入知识库"
    补充：滞后设计需给相角裕度留 3°—10° 余量。

## EX-C7-08｜习题 7-8：由谐振峰与相角裕度评价原系统并校正 { #ex-c7-08 }

**题意摘要**

对给定高阶单位反馈系统先求满足谐振峰的增益，再检查相角裕度和增益裕度。

**对应知识点**

`C7.1`、`C7.5`；母题 `Q-C7-01`。

**来源定位**

习题解印刷页 97–98（PDF p.103–104）。

### 解析路线

1. 用二阶近似把 $M_r$ 转为阻尼/期望相位裕度。
2. 由根轨迹或频率条件求 $K$。
3. 计算实际裕度，判断是否需进一步校正。

### 结果校验

习题解得到 $K\approx11$，但相角裕度/增益裕度需继续复核。

### 易错点

- 把近似 $M_r$—裕度关系当精确等式。

!!! tip "由本题补入知识库"
    补充：先满足一个指标后必须重新检查全部约束。

## EX-C7-09｜习题 7-9：随动系统的滞后校正及高频极点影响 { #ex-c7-09 }

**题意摘要**

为Ⅱ型随动系统按超调、稳态误差和带宽要求设计校正，并分析额外高频极点。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-03`。

**来源定位**

习题解印刷页 98–99（PDF p.104–105）。

### 解析路线

1. 由超调反求目标阻尼/相位裕度。
2. 由速度/加速度误差系数确定低频增益。
3. 设计滞后或复合网络；最后加入高频极点重算相位裕度。

### 结果校验

习题解给出目标交叉频率、滞后比和高频极点引起的小相位附加。

### 易错点

- 高频极点“很远”就完全忽略，不估算相位。

!!! tip "由本题补入知识库"
    补充：高频极点至少应计算在交叉频率处的相位损失。

## EX-C7-10｜习题 7-10：由校正前后 Bode 图反求校正器 { #ex-c7-10 }

**题意摘要**

已知校正前系统和目标/校正后 Bode 图，反求串联校正器传递函数。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-04`。

**来源定位**

习题解印刷页 99–100（PDF p.105–106）。

### 解析路线

1. 用校正后幅值减校正前幅值得校正器幅频。
2. 由斜率变化识别零极点。
3. 求增益并用相位曲线验证。

### 结果校验

习题解分别给出一阶/复合校正器，并验证相角裕度。

### 易错点

- 把 dB 差值换成传递函数相减。

!!! tip "由本题补入知识库"
    补充：串联校正器在 dB 图上做加法，因此可由两曲线差直接识别。

## EX-C7-11｜习题 7-11：按 $K_v$、上升时间和超调设计超前网络 { #ex-c7-11 }

**题意摘要**

为随动系统设计超前校正，满足速度误差系数、上升时间和超调约束。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 100–101（PDF p.106–107）。

### 解析路线

1. 由稳态指标确定增益。
2. 由上升时间估计目标交叉频率。

!!! tip "由本题补入知识库"
    补充：最大相位超前频率通常布置在校正后交叉频率附近。

## EX-C7-12｜习题 7-12：提高速度误差系数的滞后—超前综合 { #ex-c7-12 }

**题意摘要**

在保持原动态性能的同时把速度误差系数提高到 1000，设计滞后—超前网络。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-04`。

**来源定位**

习题解印刷页 101–102（PDF p.107–108）。

### 解析路线

1. 保留原超前部分以维持交叉频率/裕度。
2. 由精度倍率设计低频滞后部分。
3. 组合后画总 Bode 图并复核。

### 结果校验

习题解给出两段校正因子及对应电路参数。

### 易错点

- 滞后与超前零极点顺序写反。

!!! tip "由本题补入知识库"
    补充：复合校正应分工——滞后管低频精度，超前管中频稳定与速度。

## EX-C7-13｜习题 7-13：直流放大器的带宽与相角裕度校正 { #ex-c7-13 }

**题意摘要**

为直流放大器设计校正，使带宽超过 20 kHz 且相角裕度约 40°。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 102–103（PDF p.108–109）。

### 解析路线

1. 把 Hz 换算为 rad/s。
2. 按目标带宽选交叉频率。
3. 计算所需超前相位并布置零极点，复核高频滚降。

### 结果校验

习题解得到校正后截止频率约 $3.16\times10^5\,\mathrm{rad/s}$，相角裕度约 50.9°。

### 易错点

- 把 20 kHz 直接当 20 krad/s。

!!! tip "由本题补入知识库"
    补充：带宽指标常用 Hz，控制公式常用 rad/s，必须显式换算。

## EX-C7-15｜习题 7-15：超前校正器选择与 RC 实现 { #ex-c7-15 }

**题意摘要**

设计超前网络使相角裕度约 65°，并给出有源/无源 RC 实现。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 104–105（PDF p.110–111）。

### 解析路线

1. 先用一阶超前公式解 $\alpha$ 与 $T$。
2. 算校正器增益保证交叉条件。
3. 按指定网络拓扑换算电阻电容。

### 关键公式

\[
\sin\phi_m=\frac{1-\alpha}{1+\alpha}
\]

\[
\omega_m=\frac1{T\sqrt\alpha}
\]

### 结果校验

习题解给出一组 $T$、增益和 RC 数值；另给出闭环校验。

### 易错点

- 把超前形式写成滞后形式。

!!! tip "由本题补入知识库"
    补充：不同教材对 $\alpha$ 定义可能互为倒数，必须与所用传递函数形式一致。

## EX-C7-16｜习题 7-16：一个或多个超前网络的相角裕度设计 { #ex-c7-16 }

**题意摘要**

在控制器中插入一个或多个超前网络，使相角裕度达到 45°。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 105–106（PDF p.111–112）。

### 解析路线

1. 估算单个网络可提供的相位。
2. 若缺相过大，分配到多个网络，避免单段幅值峰过高。
3. 求每段参数并联合复核。

### 结果校验

习题解给出单段可行的一组时间常数。

### 易错点

- 多个网络的最大超前角直接相加，却不考虑峰值频率不同。

!!! tip "由本题补入知识库"
    补充：多段超前应让各段相位峰覆盖目标交叉频率邻域。

## EX-C7-17｜习题 7-17：同时满足速度误差、相角裕度和增益裕度 { #ex-c7-17 }

**题意摘要**

设计超前校正器，使 $K_v=20$、相角裕度不小于 50°、增益裕度不小于 10 dB。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 106（PDF p.112）。

### 解析路线

1. 由 $K_v$ 固定低频增益。
2. 由目标裕度选新交叉频率和超前角。
3. 检查相位交叉处幅值，确保增益裕度。

### 结果校验

习题解给出 $K=20$ 与一阶超前因子参数。

### 易错点

- 只检查相角裕度，不检查增益裕度。

!!! tip "由本题补入知识库"
    补充：多约束校正必须在两个交叉频率分别检查。

## EX-C7-18｜习题 7-18：第二组多裕度超前设计 { #ex-c7-18 }

**题意摘要**

在给定 $K_v=5$ 的系统上满足相角裕度和增益裕度要求。

**对应知识点**

`C7.3`、`C7.5`；母题 `Q-C7-02`。

**来源定位**

习题解印刷页 106–107（PDF p.112–113）。

### 解析路线

1. 固定低频增益。
2. 从 Bode 图寻找满足增益裕度的候选交叉频率。
3. 设计超前因子补足相位并复核。

### 结果校验

习题解得到一组较大零极点间隔的超前网络，并报告实际裕度。

### 易错点

- 候选交叉频率选得过高导致增益裕度不足。

!!! tip "由本题补入知识库"
    补充：交叉频率选择是设计核心，超前参数只是其后续实现。

## EX-C7-19｜习题 7-19：反馈校正提高带宽十倍 { #ex-c7-19 }

**题意摘要**

采用局部反馈把系统带宽提高约 10 倍，同时保持总增益不变，求反馈参数。

**对应知识点**

`C7.4`；母题 `Q-C7-05`。

**来源定位**

习题解印刷页 107–108（PDF p.113–114）。

### 解析路线

1. 化简局部反馈后的等效时间常数和静态增益。
2. 令新旧带宽比满足要求。
3. 再用前置/补偿增益保持总静态增益。

### 结果校验

习题解得到内反馈系数与前置增益的比例关系。

### 易错点

- 只提高内环增益，导致静态增益同时变化。

!!! tip "由本题补入知识库"
    补充：局部负反馈可减小等效时间常数，但需额外增益补偿静态灵敏度。

## EX-C7-20｜习题 7-20：PID 极点配置 { #ex-c7-20 }

**题意摘要**

为给定对象设计 PID，使闭环极点位于指定三个位置。

**对应知识点**

`C7.7`；母题 `Q-C7-06`。

**来源定位**

习题解印刷页 108（PDF p.114）。

### 解析路线

1. 写 PID $G_c(s)=K_Ds+K_P+K_I/s$。
2. 求闭环特征多项式。
3. 把它与期望极点多项式逐项比较。

### 关键公式

\[
G_c(s)=K_Ds+K_P+\frac{K_I}{s}
\]

### 结果校验

习题解得到约 $K_D=0.89,K_P=2.5,K_I=2.5$。

### 易错点

- PID 参数与多项式系数错位。

!!! tip "由本题补入知识库"
    补充：极点配置满足特征方程，但仍需检查零点、控制量和鲁棒性。
