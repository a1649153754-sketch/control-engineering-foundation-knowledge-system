## EX-C2-01｜习题 2-1：八类分段与调制信号的拉氏变换 { #ex-c2-01 }

**题意摘要**

对含单位阶跃、延迟、指数、正弦和分段门函数的八个时域表达式求拉氏变换。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 5–6（PDF p.11–12）。

### 解析路线

1. 先把每一项改写成标准信号与单位阶跃的乘积。
2. 对延迟项使用第二移位定理；对指数调制使用复频域平移。
3. 线性叠加后化简，保留延迟因子而不要提前展开。

### 关键公式

\[
\mathcal L\{f(t-a)u(t-a)\}=e^{-as}F(s)
\]

\[
\mathcal L\{e^{-at}f(t)\}=F(s+a)
\]

### 结果校验

结果应同时出现有理函数项与相应的 $e^{-as}$ 延迟因子；习题解逐项给出八个结果。

### 易错点

- 把 $f(t)u(t-a)$ 误当成 $f(t-a)u(t-a)$。
- 角度制与弧度制混用。

!!! tip "由本题补入知识库"
    补充：先做“时间原点平移”，再做拉氏变换，能显著减少分段积分。

## EX-C2-02｜习题 2-2：七个有理/延迟函数的拉氏反变换 { #ex-c2-02 }

**题意摘要**

对实根、共轭复根、重根及带延迟因子的七个复域函数求时域表达式。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 6–7（PDF p.12–13）。

### 解析路线

1. 先因式分解分母并判断极点类型。
2. 实单根用部分分式；共轭复根配成衰减正弦/余弦；重根保留高阶项。
3. 含 $e^{-as}$ 的结果整体乘 $u(t-a)$ 并把基本函数换成 $t-a$。

### 关键公式

\[
\mathcal L^{-1}\left\{\frac{1}{(s+a)^n}\right\}=\frac{t^{n-1}}{(n-1)!}e^{-at}
\]

\[
e^{-as}F(s)\leftrightarrow f(t-a)u(t-a)
\]

### 结果校验

应能从结果反向变换回原函数；习题解包含一组衰减振荡和一组延迟响应。

### 易错点

- 共轭极点的系数不成共轭，导致时域结果非实数。
- 重根留数只按单根计算。

!!! tip "由本题补入知识库"
    补充：反演后用初值、终值和极点位置做三重检查。

## EX-C2-03｜习题 2-3：非零初值微分方程的拉氏解法 { #ex-c2-03 }

**题意摘要**

用单边拉氏变换求三组含初始位移/速度或常值输入的微分方程响应。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 7–8（PDF p.13–14）。

### 解析路线

1. 对每阶导数保留 $x(0^-),\dot x(0^-)$ 等初值项。
2. 把输入和初值项统一移到右侧，解出 $X(s)$。
3. 部分分式反演，并用 $t=0$ 和微分方程检查初值。

### 关键公式

\[
\mathcal L\{\dot x\}=sX-x(0^-)
\]

\[
\mathcal L\{\ddot x\}=s^2X-sx(0^-)-\dot x(0^-)
\]

### 结果校验

三题分别得到常值加两个指数项、单指数项以及常值加单指数项；结果必须满足给定初值。

### 易错点

- 按传递函数零初值公式处理非零初值。
- 把 $0^-$ 与 $0^+$ 的跳变条件忽略。

!!! tip "由本题补入知识库"
    补充：初始条件等效为附加输入，但不属于外部激励传递函数。

## EX-C2-04｜习题 2-4：矩形脉冲电压的拉氏变换 { #ex-c2-04 }

**题意摘要**

把具有有限持续时间的电压脉冲写成两个阶跃之差并求变换。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 8–9（PDF p.14–15）。

### 解析路线

1. 读出幅值、起始时刻和结束时刻。
2. 写成 $A[u(t-t_1)-u(t-t_2)]$。
3. 逐项变换并提取公共因子。

### 关键公式

\[
U(s)=\frac{A}{s}\left(e^{-t_1s}-e^{-t_2s}\right)
\]

### 结果校验

习题图中幅值为 6，脉宽约 $0.2\,\mathrm{ms}$，结果应为两个延迟阶跃变换之差。

### 易错点

- 脉宽单位毫秒未换成秒。
- 漏掉 $1/s$。

!!! tip "由本题补入知识库"
    补充：任意矩形窗都可作为“开阶跃−关阶跃”处理。

## EX-C2-05｜习题 2-5：由微分方程求传递函数与终值 { #ex-c2-05 }

**题意摘要**

从二阶输入输出微分方程得到传递函数，并对单位阶跃输入计算稳态值。

**对应知识点**

`C2.3`、`C2.4`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 9（PDF p.15）。

### 解析路线

1. 在零初值下作拉氏变换。
2. 收集 $Y_o(s)$ 与 $X_i(s)$，取比值得传递函数。
3. 确认闭环/系统稳定后用终值定理。

### 关键公式

\[
G(s)=\frac{Y_o(s)}{X_i(s)}
\]

\[
y_o(\infty)=\lim_{s\to0}sY_o(s)
\]

### 结果校验

习题解得到 $G(s)=(2s+3)/(3s+2)$，单位阶跃稳态值为 $3/2$。

### 易错点

- 非严格真分式反演时忽略冲激项。
- 未检查终值定理适用条件。

!!! tip "由本题补入知识库"
    补充：相对阶次为零的系统可能含直接通道，状态空间中对应 $D\ne0$。

## EX-C2-06｜习题 2-6：四个多环方块图的等效化简 { #ex-c2-06 }

**题意摘要**

对含交叉反馈、前馈和多比较点的四个方块图求总传递函数。

**对应知识点**

`C2.5`；母题 `Q-C2-06`。

**来源定位**

习题解印刷页 9–12（PDF p.15–18）。

### 解析路线

1. 从最内层无交叉回路开始化简。
2. 比较点或引出点移动时按规则补乘/除相邻环节。
3. 每一步只改变一个局部结构，并用信号方程核对最终分母的回路项。

### 关键公式

\[
\Phi(s)=\frac{G(s)}{1\pm G(s)H(s)}
\]

### 结果校验

最终表达式应包含各独立回路增益以及相互耦合项；习题解给出图 2.3—2.6 的逐步化简。

### 易错点

- 把并联支路当串联相乘。
- 比较点移动后漏掉补偿环节。

!!! tip "由本题补入知识库"
    补充：遇到三层以上交叉回路，改用节点方程或梅逊公式通常更稳妥。

## EX-C2-07｜习题 2-7：多节点闭环传递函数 { #ex-c2-07 }

**题意摘要**

对给定多环系统求输入到两个输出节点之间的若干闭环传递函数。

**对应知识点**

`C2.5`；母题 `Q-C2-06`。

**来源定位**

习题解印刷页 12–14（PDF p.18–20）。

### 解析路线

1. 先标定每个内部节点的信号。
2. 分别令其他独立输入为零，写节点代数方程。
3. 消元后按所求输出/输入取比，并检查不同结果的共同特征分母。

### 结果校验

同一系统各闭环传递函数应共享同一个闭环特征多项式，只是分子不同。

### 易错点

- 同时保留多个独立输入却直接取比。
- 把内部节点到输出的传递函数误当全系统闭环函数。

!!! tip "由本题补入知识库"
    补充：共同分母反映内部动态，分子反映不同输入输出通道的零点。

## EX-C2-08｜习题 2-8：用梅逊公式求四个信号流图传递率 { #ex-c2-08 }

**题意摘要**

由两幅信号流图求四组输入输出传递率。

**对应知识点**

`C2.6`；母题 `Q-C2-06`。

**来源定位**

习题解印刷页 14（PDF p.20）。

### 解析路线

1. 枚举所有前向通路并求通路增益。
2. 列出所有回路和互不接触回路组，构造 $\Delta$。
3. 对每条通路构造 $\Delta_k$，代入梅逊公式。

### 关键公式

\[
P=\frac{1}{\Delta}\sum_k P_k\Delta_k
\]

\[
\Delta=1-\sum L_i+\sum L_iL_j-\cdots
\]

### 结果校验

结果的分母应与由方块图/节点方程得到的闭环特征式一致。

### 易错点

- 漏列自回路。
- 把接触回路误计入互不接触乘积。

!!! tip "由本题补入知识库"
    补充：先在图上给回路编号，再制作“接触矩阵”，可降低梅逊公式漏项概率。

## EX-C2-09｜习题 2-9：七类机械网络传递函数 { #ex-c2-09 }

**题意摘要**

对七个质量—弹簧—阻尼结构建立输入输出传递函数。

**对应知识点**

`C2.1`、`C2.7`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 14–16（PDF p.20–22）。

### 解析路线

1. 规定各质量位移正方向并画自由体图。
2. 弹簧与阻尼力统一写成相对位移/相对速度。
3. 拉氏变换后联立消元；必要时先构造力—速度或位移阻抗。

### 关键公式

\[
F_k=k(x_1-x_2)
\]

\[
F_D=D(\dot x_1-\dot x_2)
\]

### 结果校验

每个结果的分母阶次应等于独立储能状态数；极限 $k\to\infty$、$D\to0$ 应符合物理直觉。

### 易错点

- 弹簧两端力同号。
- 把串联/并联机械元件照搬电路等效。

!!! tip "由本题补入知识库"
    补充：机械网络的“等效刚度/阻尼”只在连接拓扑和端口变量定义匹配时成立。

## EX-C2-10｜习题 2-10：三个无源电路的传递函数 { #ex-c2-10 }

**题意摘要**

对三种 RLC 网络求电压传递函数。

**对应知识点**

`C2.1`、`C2.4`；母题 `Q-C2-02`。

**来源定位**

习题解印刷页 16–17（PDF p.22–23）。

### 解析路线

1. 在 $s$ 域把元件替换为阻抗或导纳。
2. 根据串并联关系用分压/节点法求比值。
3. 整理为时间常数和标准环节形式。

### 关键公式

\[
Z_R=R,\quad Z_L=sL,\quad Z_C=\frac{1}{sC}
\]

### 结果校验

结果应在 $s\to0$ 与 $s\to\infty$ 两端符合电容开短路、电感短开路的极限。

### 易错点

- 输出端负载被忽略。
- 把电容阻抗写成 $sC$。

!!! tip "由本题补入知识库"
    补充：低高频极限是电路传递函数最便宜也最有效的自检。

## EX-C2-11｜习题 2-11：四个运算放大器网络传递函数 { #ex-c2-11 }

**题意摘要**

在理想运放假设下求四种含阻容反馈网络的电压传递函数。

**对应知识点**

`C2.1`、`C2.4`；母题 `Q-C2-02`。

**来源定位**

习题解印刷页 17–18（PDF p.23–24）。

### 解析路线

1. 先写虚短与虚断条件。
2. 在反相节点列 KCL，使用输入/反馈复阻抗。
3. 对复杂网络设置中间节点并消元，最后检查直流增益与高频斜率。

### 关键公式

\[
\frac{U_o(s)}{U_i(s)}=-\frac{Z_f(s)}{Z_i(s)}
\]

### 结果校验

习题解得到比例—惯性、比例—微分等组合形式；符号应与反相/同相结构一致。

### 易错点

- 虚短误写成输入端电流相等。
- 忽略反馈电容导致阶次错误。

!!! tip "由本题补入知识库"
    补充：运放方程有效的前提是负反馈且输出未饱和。

## EX-C2-12｜习题 2-12：两种扭转机械系统传递函数 { #ex-c2-12 }

**题意摘要**

对由转动惯量、扭簧和粘性阻尼组成的两种轴系求输入转矩到角位移的传递函数。

**对应知识点**

`C2.1`、`C2.7`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 18–19（PDF p.24–25）。

### 解析路线

1. 对每个转动惯量列转矩平衡。
2. 扭簧/阻尼转矩用两端相对角位移/角速度表示。
3. 联立后消除中间角位移，或先画等效方块图。

### 关键公式

\[
J\ddot\theta=\sum T
\]

\[
T_k=k(\theta_1-\theta_2)
\]

### 结果校验

分母阶次应与两惯量系统的储能元件数一致；习题解的第二问也给出等效方块图。

### 易错点

- 把齿轮/轴比折算方向弄反。
- 忽略阻尼两端均有运动。

!!! tip "由本题补入知识库"
    补充：转动系统与平动系统可通过 $J\leftrightarrow M$、$T\leftrightarrow F$ 类比。

## EX-C2-14｜习题 2-14：机械测量结构的方程与传递函数 { #ex-c2-14 }

**题意摘要**

为带质量、弹簧、阻尼和基座运动的测量结构建立微分方程并求传递函数。

**对应知识点**

`C2.1`、`C2.7`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 20（PDF p.26）。

### 解析路线

1. 明确绝对位移与相对位移。
2. 对质量列牛顿方程，所有弹簧阻尼力按两端相对量写。
3. 选择题目要求的输入输出，拉氏变换后取比。

### 关键公式

\[
M\ddot y+D(\dot y-\dot x)+k(y-x)=f(t)
\]

### 结果校验

结果中基座输入与外力输入应形成不同分子，但共享系统动态分母。

### 易错点

- 把相对变形 $y-x$ 写成 $y$。
- 没有区分基座激励与外力激励。

!!! tip "由本题补入知识库"
    补充：基座激励问题通常先改用相对坐标可显著简化。

## EX-C2-15｜习题 2-15：含参考、噪声和反馈信号的多输入系统 { #ex-c2-15 }

**题意摘要**

对多输入多输出闭环图分别求参考、噪声及反馈支路到不同输出的传递函数。

**对应知识点**

`C2.5`；母题 `Q-C2-06`。

**来源定位**

习题解印刷页 20–21（PDF p.26–27）。

### 解析路线

1. 采用叠加原理，一次只保留一个独立输入。
2. 先求共同回路增益和闭环特征分母。
3. 逐通道写分子，注意噪声注入点位于对象前还是测量端。

### 结果校验

各通道具有共同闭环分母；习题解列出 $X_o/X_i,Y/X_i,B/X_i,E/X_i$ 等多组结果。

### 易错点

- 噪声通道符号与参考通道照抄。
- 忘记输出选择点不同导致额外串联因子。

!!! tip "由本题补入知识库"
    补充：灵敏度函数与互补灵敏度函数可统一描述参考、扰动和噪声通道。

## EX-C2-16｜习题 2-16：直流电机的控制与负载扰动通道 { #ex-c2-16 }

**题意摘要**

求直流电机转速对电枢电压和负载转矩的传递函数。

**对应知识点**

`C2.1`、`C2.7`；母题 `Q-C2-03`。

**来源定位**

习题解印刷页 21–22（PDF p.27–28）。

### 解析路线

1. 写电枢回路 $u=Ri+L\dot i+K_e\omega$。
2. 写机械方程 $J\dot\omega+D\omega=K_Ti-M_L$。
3. 在 $s$ 域消去电流，分别保留电压或负载转矩输入。

### 关键公式

\[
U_a=(R+Ls)I+K_e\Omega
\]

\[
(Js+D)\Omega=K_TI-M_L
\]

### 结果校验

两个通道共享同一分母，负载转矩通道分子带负号。

### 易错点

- 反电势符号错误。
- 把 $K_T$ 与 $K_e$ 的单位/数值条件混同。

!!! tip "由本题补入知识库"
    补充：同一对象的控制通道和扰动通道必须一起建模，后续抗扰设计才完整。

## EX-C2-17｜习题 2-17：周期方波的拉氏变换 { #ex-c2-17 }

**题意摘要**

对周期脉冲/方波使用周期函数公式或阶跃展开求拉氏变换。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 22（PDF p.28）。

### 解析路线

1. 先写一个周期内的波形。
2. 使用周期函数变换公式，或把无限延迟项写成等比级数。
3. 化简并用周期极限检查。

### 关键公式

\[
F(s)=\frac{\int_0^T f(t)e^{-st}\,dt}{1-e^{-sT}}
\]

### 结果校验

习题解把阶跃展开与周期公式两种方法对照，结果一致。

### 易错点

- 只变换一个周期而漏除 $1-e^{-sT}$。
- 起始相位/占空比读错。

!!! tip "由本题补入知识库"
    补充：周期函数拉氏变换是“单周期加权面积÷几何级数因子”。

## EX-C2-18｜习题 2-18：两质量系统的方块图与传递函数 { #ex-c2-18 }

**题意摘要**

由两质量—弹簧—阻尼结构建立方块图并求外力到指定质量位移的传递函数。

**对应知识点**

`C2.7`、`C2.8`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 22（PDF p.28）。

### 解析路线

1. 分别对两质量列受力平衡。
2. 把加速度到位移的两次积分显式画入方块图。
3. 消除耦合力或用矩阵方程求所需传递函数。

### 结果校验

最终分母为四阶，且在两质量/刚度极限情况下可退化到低阶模型。

### 易错点

- 中间相互作用力只作用在一个质量上。
- 方块图积分环节数量不足。

!!! tip "由本题补入知识库"
    补充：多自由度系统适合用动态刚度矩阵 $Ms^2+Ds+K$ 统一表示。

## EX-C2-19｜习题 2-19：两质量系统的多通道传递函数 { #ex-c2-19 }

**题意摘要**

对另一两质量系统求多个外力到两个位移的传递函数。

**对应知识点**

`C2.7`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 23–24（PDF p.29–30）。

### 解析路线

1. 建立矩阵形式 $\mathbf Z(s)\mathbf X(s)=\mathbf F(s)$。
2. 对不同输入用克拉默法则或矩阵求逆得到各元素。
3. 检查互易结构在对称系统中是否满足交叉传递函数相等。

### 关键公式

\[
\mathbf X(s)=[Ms^2+Ds+K]^{-1}\mathbf F(s)
\]

### 结果校验

四个通道共享行列式分母，分子由对应余子式决定。

### 易错点

- 逐个通道重复列方程造成符号不一致。
- 忽略输入力的作用方向。

!!! tip "由本题补入知识库"
    补充：传递函数矩阵能同时保存所有输入输出通道，避免重复消元。

## EX-C2-20｜习题 2-20：相位平移与延迟正弦信号 { #ex-c2-20 }

**题意摘要**

把三条相位不同/延迟不同的正弦曲线写成时域表达式并求拉氏变换。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 23–24（PDF p.29–30）。

### 解析路线

1. 根据图形读出幅值、频率、相位和延迟。
2. 优先写成标准正弦加阶跃窗；延迟信号先平移再变换。
3. 用 $t=0$ 值和初始斜率核对相位。

### 关键公式

\[
\mathcal L\{\sin\omega t\}=\frac{\omega}{s^2+\omega^2}
\]

### 结果校验

习题解把波形分解为正弦/余弦与延迟阶跃的组合。

### 易错点

- 把图上水平位移直接当相位角而未乘频率。

!!! tip "由本题补入知识库"
    补充：时间延迟 $t_0$ 与相位差满足 $\varphi=-\omega t_0$，仅对单一频率成立。

## EX-C2-21｜习题 2-21：双质量受多力输入的传递函数 { #ex-c2-21 }

**题意摘要**

对双质量、双弹簧、阻尼结构求四个外力—位移通道。

**对应知识点**

`C2.7`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 24–25（PDF p.30–31）。

### 解析路线

1. 选两位移为广义坐标。
2. 列矩阵动态刚度方程。
3. 用行列式或伴随矩阵读取各传递函数，并做静态 $s=0$ 检查。

### 结果校验

各传递函数分母相同；静态极限应退化为纯弹簧网络的柔度关系。

### 易错点

- 只检查动态阶次而不做静态柔度核对。

!!! tip "由本题补入知识库"
    补充：$s=0$ 检查得到静柔度，$s\to\infty$ 检查惯性主导，是多自由度模型的两个强校验。

## EX-C2-22｜习题 2-22：三条分段曲线的拉氏变换 { #ex-c2-22 }

**题意摘要**

对斜坡截断、分段线性和周期三角波求拉氏变换。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 24–25（PDF p.30–31）。

### 解析路线

1. 把折线写成若干延迟斜坡的叠加。
2. 有限区间函数用开关阶跃截断；周期波形用周期公式。
3. 化简后检查函数在各断点前后的连续性。

### 关键公式

\[
(t-a)u(t-a)\leftrightarrow \frac{e^{-as}}{s^2}
\]

### 结果校验

习题解分别得到带 $e^{-as}$ 的有理式和含 $1-e^{-sT}$ 的周期式。

### 易错点

- 仅按每段独立积分，断点处系数容易错。

!!! tip "由本题补入知识库"
    补充：折线信号最稳的表示是“初始斜率 + 每次斜率变化×延迟斜坡”。

## EX-C2-23｜习题 2-23：四个卷积积分 { #ex-c2-23 }

**题意摘要**

计算常数、指数和正弦等函数的卷积。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

**来源定位**

习题解印刷页 25（PDF p.31）。

### 解析路线

1. 写定义并明确积分上下限。
2. 能用变换时，先分别求拉氏变换再相乘；再反演。
3. 直接积分与变换法互相核对。

### 关键公式

\[
(f*g)(t)=\int_0^t f(\tau)g(t-\tau)\,d\tau
\]

\[
\mathcal L\{f*g\}=F(s)G(s)
\]

### 结果校验

习题解包含 $1*1=t$、$t*t=t^3/6$ 等基准结果。

### 易错点

- 卷积不满足普通点乘规则。
- 把 $g(t-\tau)$ 写成 $g(\tau-t)$。

!!! tip "由本题补入知识库"
    补充：卷积可解释为系统对过去输入的加权累积，是脉冲响应方法的核心。

## EX-C2-25｜习题 2-25：扭转轴系的力—角位移传递函数 { #ex-c2-25 }

**题意摘要**

对含扭转刚度、转动惯量和粘性阻尼的轴系求外力/力矩到角位移的传递函数。

**对应知识点**

`C2.1`、`C2.7`；母题 `Q-C2-01`。

**来源定位**

习题解印刷页 26（PDF p.32）。

### 解析路线

1. 先由半径把线力换成转矩。
2. 列转动平衡方程。
3. 在 $s$ 域取角位移与输入比，并检查单位。

### 关键公式

\[
T=rF
\]

\[
J\ddot\theta+D\dot\theta+k\theta=T
\]

### 结果校验

结果应为标准二阶振荡环节，分子含作用半径。

### 易错点

- 线位移和角位移未通过半径换算。

!!! tip "由本题补入知识库"
    补充：输入端口改变时，系统极点不变而分子和量纲改变。

## EX-C2-26｜习题 2-26：由代数方程绘制信号流图 { #ex-c2-26 }

**题意摘要**

把两组联立代数关系转为信号流图并由图求输入输出关系。

**对应知识点**

`C2.6`、`C2.8`；母题 `Q-C2-06`。

**来源定位**

习题解印刷页 26（PDF p.32）。

### 解析路线

1. 每个变量建立一个节点。
2. 把“某变量乘系数进入另一方程”画成有向支路。
3. 用梅逊公式或节点回代求总传递率。

### 结果校验

所得传递率应与直接联立消元完全一致。

### 易错点

- 支路方向按视觉顺序而非因果关系绘制。
- 常数项/输入节点漏画。

!!! tip "由本题补入知识库"
    补充：信号流图是线性代数方程的图表示，方向由“谁决定谁”而非物理流向决定。
