## EX-C8-01｜习题 8-1：六组开环极点的根轨迹草图 { #ex-c8-01 }

**题意摘要**

对六组开环极点/零点配置手绘根轨迹。

**对应知识点**

`C8.1`、`C8.2`；母题 `Q-C8-02`。

**来源定位**

习题解印刷页 109–110（PDF p.115–116）。

### 解析路线

1. 标出开环极点与零点，分支数等于极点数。
2. 判断实轴根轨迹段、渐近线和重心。
3. 求分离点、出射角或虚轴交点，标增益方向。

### 结果校验

习题解给出图 8.1—8.6，覆盖全实极点、共轭极点和椭圆/圆形轨迹。

### 易错点

- 只连接极点与零点，不按相角条件筛选实轴段。

!!! tip "由本题补入知识库"
    补充：根轨迹手绘应至少标出起点、终点、方向、渐近线和关键交点。

## EX-C8-02｜习题 8-2：圆形根轨迹的解析证明 { #ex-c8-02 }

**题意摘要**

对 $G(s)=K(s+z)/[s(s+p)]$（$z>p>0$）证明部分根轨迹为圆，并求圆心、半径。

**对应知识点**

`C8.1`、`C8.2`；母题 `Q-C8-02`。

**来源定位**

习题解印刷页 110–111（PDF p.116–117）。

### 解析路线

1. 设 $s=\sigma+j\omega$，写相角条件。
2. 对正切关系作代数消元。
3. 整理为圆的标准方程。

### 关键公式

\[
(\sigma+z)^2+\omega^2=z^2-pz
\]

### 结果校验

习题解得到圆心 $(-z,0)$，半径 $\sqrt{z^2-pz}$（按教材符号方向）。

### 易错点

- 圆心符号因 $s+z$ 与 $s-z$ 记号混淆。

!!! tip "由本题补入知识库"
    补充：某些低阶根轨迹可由相角条件直接化为圆锥曲线。

## EX-C8-03｜习题 8-3：三阶系统分离点与根轨迹 { #ex-c8-03 }

**题意摘要**

对 $K(s+5)/[s(s+2)(s+3)]$ 求分离点并画根轨迹。

**对应知识点**

`C8.2`、`C8.4`；母题 `Q-C8-03`。

**来源定位**

习题解印刷页 111（PDF p.117）。

### 解析路线

1. 由特征方程解出 $K(s)$。
2. 令 $dK/ds=0$ 得候选分离点。
3. 用实轴段/相角条件筛选，再补渐近线与方向。

### 关键公式

\[
\frac{dK(s)}{ds}=0
\]

### 结果校验

习题解给出有效分离点约 $s=-0.9$。

### 易错点

- 导数方程所有根都保留。

!!! tip "由本题补入知识库"
    补充：分离点候选必须同时位于实际实轴根轨迹段且对应 $K>0$。

## EX-C8-04｜习题 8-4：三阶惯性对象的根轨迹绘制 { #ex-c8-04 }

**题意摘要**

对 $G(s)=K/[s(0.05s^2+0.4s+1)]$ 绘制 $K:0\to\infty$ 的闭环根轨迹。

**对应知识点**

`C8.2`、`C8.4`；母题 `Q-C8-02`。

**来源定位**

习题解印刷页 111（PDF p.117）。

### 解析路线

1. 求开环极点并标图。
2. 计算渐近线、重心和实轴段。
3. 求分离点/虚轴交点，按相角条件连接分支。

### 结果校验

习题解给出图 8.9，轨迹从原点和一对实/复极点出发。

### 易错点

- 二次因子极点未先精确求出。

!!! tip "由本题补入知识库"
    补充：手绘前先把二次因子极点数值化可避免拓扑判断错误。

## EX-C8-05｜习题 8-5：闭环特征参数 $a$ 改变时的根轨迹 { #ex-c8-05 }

**题意摘要**

对特征方程 $s^2(s+a)+K(s+1)=0$，分别分析 $a>1,a=1,a<1,a=0$ 的根轨迹与稳定性。

**对应知识点**

`C8.3`；母题 `Q-C8-05`。

**来源定位**

习题解印刷页 111–112（PDF p.117–118）。

### 解析路线

1. 整理为开环 $K(s+1)/[s^2(s+a)]$。
2. 按 $a$ 的相对位置改变极点—零点排列。
3. 分别画根轨迹并由虚轴/右半平面分支判断稳定。

### 结果校验

习题解指出 $a>1$ 稳定、$a=1$ 等幅振荡、$a<1$ 不稳定、$a=0$ 不稳定。

### 易错点

- 用一张固定根轨迹概括所有 $a$。

!!! tip "由本题补入知识库"
    补充：参数改变极零点相对顺序时，根轨迹拓扑可能发生质变。

## EX-C8-06｜习题 8-6：等阻尼线选取增益 { #ex-c8-06 }

**题意摘要**

对 $G(s)=K(s+2)/[s(s+1)(s+3)]$ 画根轨迹，并在 $\zeta=0.707$ 下求增益。

**对应知识点**

`C8.2`、`C8.5`；母题 `Q-C8-06`。

**来源定位**

习题解印刷页 112–113（PDF p.118–119）。

### 解析路线

1. 完成根轨迹关键要素。
2. 画 $\zeta=0.707$ 等阻尼射线。
3. 求交点并用幅值条件计算 $K$。

### 关键公式

\[
K=\frac{\prod|s-p_i|}{\prod|s-z_i|}
\]

### 结果校验

习题解得到 $K\approx0.95$。

### 易错点

- 只凭图读 K，不用幅值条件核算。

!!! tip "由本题补入知识库"
    补充：根轨迹图确定极点位置，增益必须由幅值条件求。

## EX-C8-07｜习题 8-7：以零点位置为参数的根轨迹 { #ex-c8-07 }

**题意摘要**

对 $G(s)=\tfrac14(s+a)/[s^2(s+1)]$ 绘制 $a:0\to\infty$ 的参数根轨迹。

**对应知识点**

`C8.3`；母题 `Q-C8-05`。

**来源定位**

习题解印刷页 113（PDF p.119）。

### 解析路线

1. 写特征方程 $4s^2(s+1)+s+a=0$。
2. 把含 $a$ 项分离成 $1+a/B(s)=0$ 的形式。
3. 把 $a$ 视为等效根轨迹增益，按规则作图。

### 结果校验

习题解给出图 8.15，根轨迹相对虚轴呈共轭对称。

### 易错点

- 仍把原系统增益当作变化参数。

!!! tip "由本题补入知识库"
    补充：参数根轨迹的关键是把特征式整理为 $A(s)+\lambda B(s)=0$。

## EX-C8-08｜习题 8-8：测速反馈参数根轨迹与时域性能 { #ex-c8-08 }

**题意摘要**

对含测速反馈 $1+K_hs$ 的系统，分别研究 $K$ 根轨迹、$K_h$ 参数根轨迹及若干参数下的 $M_p,t_s$。

**对应知识点**

`C8.3`、`C8.5`；母题 `Q-C8-05`。

**来源定位**

习题解印刷页 113–115（PDF p.119–121）。

### 解析路线

1. 固定 $K_h$ 时写等效开环零点并画普通根轨迹。
2. 固定 $K$ 时把 $K_h$ 从特征式中分离，画参数根轨迹。
3. 由闭环二阶分母求 $\zeta,\omega_n$ 与指标。

### 结果校验

习题解给出 $K_h=0.5,K=10$ 时极点 $-3\pm j$、$\zeta\approx0.95$；并比较 $K_h=0,0.5,4$ 的超调与调整时间。

### 易错点

- 把测速反馈只看作增益变化。

!!! tip "由本题补入知识库"
    补充：测速反馈引入闭环零点/改变一次项，对阻尼和响应系数均有影响。

## EX-C8-09｜习题 8-9：按 $K_v$ 和主导极点配置校正零点 { #ex-c8-09 }

**题意摘要**

为 $10/[s(s+2)(s+8)]$ 设计校正，使 $K_v=80$ 且主导极点位于 $-2\pm j2\sqrt3$。

**对应知识点**

`C8.5`；母题 `Q-C8-06`。

**来源定位**

习题解印刷页 115–116（PDF p.121–122）。

### 解析路线

1. 用 $K_v$ 条件建立 $Ka$ 关系。
2. 把期望极点代入闭环特征多项式，比较实虚部/标准二阶系数。
3. 解出校正增益和零点位置并画根轨迹验证。

### 结果校验

习题解得到约 $K=1.065,a=15$。

### 易错点

- 只满足极点位置，未同时满足稳态误差系数。

!!! tip "由本题补入知识库"
    补充：根轨迹设计常需一个稳态约束和一个动态约束联合确定两个参数。

## EX-C8-10｜习题 8-10：四阶系统等阻尼线求增益 { #ex-c8-10 }

**题意摘要**

对 $K/[s(s+1)(s+2)(s+8)]$，要求闭环主导极点阻尼比 0.5，求开环增益。

**对应知识点**

`C8.5`；母题 `Q-C8-06`。

**来源定位**

习题解印刷页 116（PDF p.122）。

### 解析路线

1. 画根轨迹与 $\zeta=0.5$ 等阻尼线。
2. 找交点并判断其是否为主导极点。
3. 由幅值条件求 $K$，再检查其余极点距离。

### 结果校验

习题解由图 8.20 得到 $K\approx7.5$。

### 易错点

- 只找到等阻尼交点，不检查非主导极点。

!!! tip "由本题补入知识库"
    补充：高阶系统用等阻尼线设计后，必须复核剩余极点是否足够远。
