## EX-C9-01｜习题 9-1：典型非线性的描述函数与 $-1/N$ 曲线 { #ex-c9-01 }

**题意摘要**

对给定分段非线性求描述函数，画 $-1/N(A)$ 并求 $A=0,1,\infty$ 的特征点。

**对应知识点**

`C9.2`；母题 `Q-C9-02`。

**来源定位**

习题解印刷页 117–118（PDF p.123–124）。

### 解析路线

1. 写非线性对 $A\sin\omega t$ 的输出。
2. 积分求基波正弦/余弦系数。
3. 除以输入幅值形成 $N(A)$，再取负倒数。

### 关键公式

\[
N(A)=\frac{B_1+jA_1}{A}
\]

### 结果校验

习题解给出随幅值变化的实轴曲线与三个极限点。

### 易错点

- 把非线性静态斜率直接当描述函数。

!!! tip "由本题补入知识库"
    补充：描述函数是输入幅值相关的基波等效增益，不是精确线性化。

## EX-C9-02｜习题 9-2：自治系统等倾线与参数相图 { #ex-c9-02 }

**题意摘要**

对二阶非线性自治系统求等倾线，并比较参数 $k=0,-2,1$ 时的相平面。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 118（PDF p.124）。

### 解析路线

1. 令 $x_1=x,x_2=\dot x$。
2. 求 $dx_2/dx_1$ 并令其等于常数斜率 $k$。
3. 画若干等倾线并按向量场方向连接相轨迹。

### 结果校验

习题解给出等倾线族和不同参数下的相图。

### 易错点

- 把等倾线当成相轨迹。

!!! tip "由本题补入知识库"
    补充：等倾线只给相轨迹切线方向，相轨迹需由方向场积分形成。

## EX-C9-03｜习题 9-3：分区相轨迹与特殊轨迹 { #ex-c9-03 }

**题意摘要**

对分段非线性系统分别求两个区域的相轨迹方程，并找经过指定点的特殊轨迹。

**对应知识点**

`C9.3`；母题 `Q-C9-05`。

**来源定位**

习题解印刷页 118–119（PDF p.124–125）。

### 解析路线

1. 在每个区域写对应微分方程。
2. 消去时间积分得到第一积分。
3. 在切换曲线上保证状态连续，用指定点定积分常数。

### 结果校验

习题解得到两组积分曲线，并给出通过 $(0,2)$ 的分段轨迹。

### 易错点

- 跨越切换边界时重新任意选常数。

!!! tip "由本题补入知识库"
    补充：分段相轨迹在切换边界状态连续，但切线可发生变化。

## EX-C9-04｜习题 9-4：给定分段增益非线性的描述函数 { #ex-c9-04 }

**题意摘要**

求图示非线性环节的描述函数。

**对应知识点**

`C9.2`；母题 `Q-C9-02`。

**来源定位**

习题解印刷页 119（PDF p.125）。

### 解析路线

1. 利用奇对称/偶对称先判断是否有相位项。
2. 按阈值角分段积分输出基波。
3. 写成幅值比形式并检查小/大幅值极限。

### 结果校验

习题解给出含反三角函数和根式的 $N(A)$。

### 易错点

- 积分区间未按阈值角切分。

!!! tip "由本题补入知识库"
    补充：阈值非线性常通过 $\theta_0=\arcsin(b/A)$ 确定积分边界。

## EX-C9-05｜习题 9-5：非线性反馈系统的相平面稳定性与响应 { #ex-c9-05 }

**题意摘要**

对含平方/分段非线性的反馈系统，用相平面判断稳定性并求给定初值响应。

**对应知识点**

`C9.3`；母题 `Q-C9-05`。

**来源定位**

习题解印刷页 120（PDF p.126）。

### 解析路线

1. 由方块图写二阶自治方程。
2. 分别在状态正负区域积分相轨迹。
3. 由初值确定轨迹并判断是否趋向原点/发散。

### 结果校验

习题解指出不同初值/区域可对应稳定或不稳定运动。

### 易错点

- 仅在线性化点附近判断全局稳定。

!!! tip "由本题补入知识库"
    补充：非线性系统稳定性可能依赖初始条件，需区分局部与全局。

## EX-C9-06｜习题 9-6：一阶非线性方程的相轨迹 { #ex-c9-06 }

**题意摘要**

由 $T\dot x+x=A$ 一类方程画不同常值输入下的相轨迹/等倾线。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 120–121（PDF p.126–127）。

### 解析路线

1. 把方程改写成 $\dot x=f(x)$。
2. 求平衡点并看两侧符号。
3. 在相线上标方向与稳定性。

### 结果校验

习题解给出一组水平相线/等倾线并指出平衡点。

### 易错点

- 一阶系统硬画二维闭合轨迹。

!!! tip "由本题补入知识库"
    补充：一维自治系统不能产生非平凡周期轨道。

## EX-C9-07｜习题 9-7：描述函数法求极限环（一） { #ex-c9-07 }

**题意摘要**

对含典型非线性和线性环节的闭环系统，求可能的自振幅值、频率及稳定性。

**对应知识点**

`C9.2`；母题 `Q-C9-03`。

**来源定位**

习题解印刷页 121–122（PDF p.127–128）。

### 解析路线

1. 求 $N(A)$。
2. 画/联立 $G(j\omega)=-1/N(A)$。
3. 由交点求 $A,\omega$，再按曲线穿越方向判断极限环稳定性。

### 结果校验

习题解得到一组候选频率与幅值，并给出极限环图。

### 易错点

- 有交点就直接断言稳定极限环。

!!! tip "由本题补入知识库"
    补充：交点只给存在性近似，稳定性还需看扰动后幅值演化方向。

## EX-C9-08｜习题 9-8：描述函数法求极限环（二） { #ex-c9-08 }

**题意摘要**

对另一非线性闭环比较不同参数下是否产生自振。

**对应知识点**

`C9.2`；母题 `Q-C9-03`。

**来源定位**

习题解印刷页 122–123（PDF p.128–129）。

### 解析路线

1. 求非线性描述函数。
2. 求线性频率特性与 $-1/N$ 交点。
3. 检查交点是否在有效幅值区间。

### 结果校验

习题解给出临界频率/幅值并画自振轨迹。

### 易错点

- 忽略描述函数公式的幅值适用范围。

!!! tip "由本题补入知识库"
    补充：死区、饱和等描述函数只在输入幅值超过阈值后有相应表达式。

## EX-C9-09｜习题 9-9：由初值求相轨迹与到达时间 { #ex-c9-09 }

**题意摘要**

给定非线性二阶系统初值，画相轨迹并计算到达某状态所需时间。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 123（PDF p.129）。

### 解析路线

1. 求相轨迹第一积分。
2. 由初值确定常数并选正确分支。
3. 沿轨迹利用 $dt=dx/\dot x$ 积分求时间。

### 结果校验

习题解给出含反三角/对数的时间积分与对应轨迹。

### 易错点

- 相轨迹方程求出后没有确定运动方向。

!!! tip "由本题补入知识库"
    补充：相轨迹给几何路径，时间参数需额外沿轨迹积分。

## EX-C9-10｜习题 9-10：奇点类型与相平面图 { #ex-c9-10 }

**题意摘要**

判断非线性二阶系统奇点类型并画相平面图。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 123–124（PDF p.129–130）。

### 解析路线

1. 解 $\dot x_1=\dot x_2=0$ 找奇点。
2. 在奇点处线性化并求雅可比特征值。
3. 结合非线性第一积分/方向场画全局相图。

### 结果校验

习题解先判奇点，再画出随参数 $k$ 变化的相轨迹族。

### 易错点

- 只用线性化结果描述远离奇点的轨迹。

!!! tip "由本题补入知识库"
    补充：线性化用于局部分类，退化/零实部情形需更高阶分析。

## EX-C9-11｜习题 9-11：多初值手绘相轨迹 { #ex-c9-11 }

**题意摘要**

对给定系统和两组初值，手工绘制相平面轨迹。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 124–125（PDF p.130–131）。

### 解析路线

1. 求等倾线或第一积分。
2. 标奇点和特殊曲线。
3. 将各初值代入确定轨迹族成员和方向。

### 结果校验

习题解给出多条从不同初值出发的轨迹图。

### 易错点

- 轨迹相交。

!!! tip "由本题补入知识库"
    补充：自治常微分方程解唯一时，不同相轨迹除奇点外不能相交。

## EX-C9-12｜习题 9-12：由三个传递函数画线性相图 { #ex-c9-12 }

**题意摘要**

对三个二阶线性系统用相平面法画轨迹并判断稳定性。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 126（PDF p.132）。

### 解析路线

1. 由分母写状态方程。
2. 求特征值或相轨迹方程。
3. 按节点、焦点、中心或鞍点分类。

### 结果校验

习题解给出稳定焦点、中心/临界和不稳定情形的相图。

### 易错点

- 把传递函数零点用于奇点分类。

!!! tip "由本题补入知识库"
    补充：自由响应相图由系统矩阵特征值决定，传递函数零点不改变状态矩阵极点。

## EX-C9-13｜习题 9-13：继电/限幅电路的描述函数 { #ex-c9-13 }

**题意摘要**

根据运放限幅电路求静态非线性曲线并计算描述函数。

**对应知识点**

`C9.2`；母题 `Q-C9-02`。

**来源定位**

习题解印刷页 126（PDF p.132）。

### 解析路线

1. 由电阻与电源限幅求分段输入输出关系。
2. 判断对称性。
3. 按分段区间积分基波。

### 结果校验

!!! tip "由本题补入知识库"

## EX-C9-14｜习题 9-14：滞环非线性的描述函数 { #ex-c9-14 }

**题意摘要**

对带滞环宽度和输出高度的非线性求复数描述函数。

**对应知识点**

`C9.2`；母题 `Q-C9-02`。

**来源定位**

习题解印刷页 126–127（PDF p.132–133）。

### 解析路线

1. 确定切换角。
2. 分别求同相基波与正交基波。
3. 组成复数 $N(A)$，解释负虚部对应滞后。

### 结果校验

习题解给出同时含实部和虚部的 $N(A)$。

### 易错点

- 把滞环当普通继电，只求实数描述函数。

!!! tip "由本题补入知识库"
    补充：具有记忆/滞环的非线性描述函数一般为复数。

## EX-C9-15｜习题 9-15：含非线性的方块图等效变换 { #ex-c9-15 }

**题意摘要**

把四种线性—非线性混合方块图变换为便于描述函数分析的标准形式，并写等效线性部分。

**对应知识点**

`C9.1`、`C9.2`；母题 `Q-C9-01`。

**来源定位**

习题解印刷页 127（PDF p.133）。

### 解析路线

1. 保持非线性输入输出变量不变。
2. 只对其余线性环节作方块图变换。
3. 写出非线性外看到的等效 $G(s)$。

### 结果校验

习题解列出四个等效线性传递函数。

### 易错点

- 把非线性块像线性增益一样任意跨比较点移动。

!!! tip "由本题补入知识库"
    补充：非线性环节不能使用一般线性方块图交换律，需保持其端口变量。

## EX-C9-16｜习题 9-16：分段非线性系统的极限环与参数区间 { #ex-c9-16 }

**题意摘要**

对含死区/继电特性的系统，在不同参数区间判断相轨迹和极限环。

**对应知识点**

`C9.2`、`C9.3`；母题 `Q-C9-03`。

**来源定位**

习题解印刷页 127–129（PDF p.133–135）。

### 解析路线

1. 写各分区的状态方程。
2. 求分区相轨迹并在边界拼接。
3. 判断闭合轨迹存在性与吸引/排斥方向。

### 结果校验

习题解给出参数分区、相轨迹图，并指出部分参数下形成稳定极限环。

### 易错点

- 跨区时速度/状态连续性处理错误。

!!! tip "由本题补入知识库"
    补充：分段线性系统的极限环可通过逐区解析拼接而非描述函数近似。

## EX-C9-17｜习题 9-17：平衡点分类与相轨迹 { #ex-c9-17 }

**题意摘要**

判断四个系统平衡点性质并画相轨迹，其中包含稳定/不稳定焦点与鞍点。

**对应知识点**

`C9.3`；母题 `Q-C9-04`。

**来源定位**

习题解印刷页 129–130（PDF p.135–136）。

### 解析路线

1. 解平衡点。
2. 求线性化矩阵特征值。
3. 按实部、判别式和行列式分类，并结合非线性项修正。

### 结果校验

习题解给出四幅相图及对应稳定性。

### 易错点

- 只按一个平衡点分析多平衡系统。

!!! tip "由本题补入知识库"
    补充：多个平衡点的吸引域由分界轨迹（稳定流形）分隔。

## EX-C9-18｜习题 9-18：指定初值下的非线性相轨迹 { #ex-c9-18 }

**题意摘要**

对图示系统从给定初始状态出发求相轨迹并判断是否收敛。

**对应知识点**

`C9.3`；母题 `Q-C9-05`。

**来源定位**

习题解印刷页 130（PDF p.136）。

### 解析路线

1. 由方块图写状态方程。
2. 消去时间求 $dx_2/dx_1$ 或找第一积分。
3. 代初值确定常数，标方向与终点。

### 结果校验

习题解得到绕某区域的闭合/收敛轨迹图。

### 易错点

- 只画轨迹形状不标初值对应分支。

!!! tip "由本题补入知识库"
    补充：同一相轨迹族中，初值决定具体轨迹和运动方向。
