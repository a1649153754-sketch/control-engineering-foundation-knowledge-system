# 习题解逐题解析

> 覆盖配套《控制工程基础（第4版）习题解》第 1—10 章全部 **193 道题**。每题均采用原创重述，不复制扫描页或整段原解；核心数字与结论以习题解为核对基准。

## 阅读方式

每张解析卡固定包含：

1. **题意摘要**：只保留任务结构；
2. **对应知识点**：链接稳定节点和母题；
3. **解析路线**：说明第一动作、推导顺序和检查点；
4. **关键公式**：使用可渲染 LaTeX；
5. **结果校验**：给出习题解中的关键结果或结构性检查；
6. **易错与补充**：把本题反哺为可迁移结论。

!!! warning "版权与使用边界"
    本项目不收录来源 PDF、题目扫描图或逐字答案。阅读解析时仍应以你合法持有的教材和习题解核对图形、参数与完整题面。

## 统一错误标签

- `MODEL`：对象、坐标、端口或初始条件建错；
- `STRUCT`：方块图、信号流图或反馈符号错误；
- `COND`：公式/判据条件漏检；
- `ALG`：代数、部分分式、复数象限或单位错误；
- `INTERP`：对极点、零点、曲线和性能含义解释错误；
- `VERIFY`：没有做极限、终值、量纲、稳定性或软件交叉检查。
