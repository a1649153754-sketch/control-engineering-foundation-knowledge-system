## EX-C4-01｜习题 4-1：幅值比与分贝互换 { #ex-c4-01 }

**题意摘要**

把若干幅值比换算为分贝，并把分贝值换回幅值比。

**对应知识点**

`C4.1`、`C4.3`；母题 `Q-C4-03`。

**来源定位**

习题解印刷页 46（PDF p.52）。

### 解析路线

1. 确认是幅值比还是功率比。
2. 幅值比用 $20\log_{10}$，反算用 $10^{L/20}$。
3. 对 1、10、0.1 等基准做数量级检查。

### 关键公式

\[
L(\omega)=20\log_{10}A(\omega)
\]

\[
A=10^{L/20}
\]

### 结果校验

习题解列出 2、5、10、40、100、0.01、1/10、0.0025、1、0 等的对应值。

### 易错点

- 把幅值比误用 $10\log_{10}$。
- $A=0$ 时写成有限 dB。

!!! tip "由本题补入知识库"
    补充：0 dB 表示幅值比 1，不表示信号为零。

## EX-C4-02｜习题 4-2：指定频率下的幅值与相位 { #ex-c4-02 }

**题意摘要**

对两个传递函数在 $\omega=2,20\,\mathrm{rad/s}$ 处求幅值和相位。

**对应知识点**

`C4.1`；母题 `Q-C4-01`。

**来源定位**

习题解印刷页 46–47（PDF p.52–53）。

### 解析路线

1. 令 $s=j\omega$。
2. 按因子分别求模与相角再累加。
3. 相角使用正确象限，并统一到连续相位分支。

### 关键公式

\[
G(j\omega)=A(\omega)e^{j\varphi(\omega)}
\]

### 结果校验

习题解给出积分环节在两个频率处的幅值及 $-90^\circ$ 相位，并给出二阶因子结果。

### 易错点

- Hz 与 rad/s 混用。
- 反正切没有按象限修正。

!!! tip "由本题补入知识库"
    补充：频率响应的模相可按因子乘法/相角加法快速计算。

## EX-C4-03｜习题 4-3：频率特性的四种等价表示 { #ex-c4-03 }

**题意摘要**

对两个传递函数求幅频、相频、实频和虚频特性。

**对应知识点**

`C4.1`；母题 `Q-C4-01`。

**来源定位**

习题解印刷页 47（PDF p.53）。

### 解析路线

1. 代入 $s=j\omega$。
2. 有理化分母，分离实部和虚部。
3. 由实虚部再算模与相位，互相核对。

### 关键公式

\[
A=\sqrt{U^2+V^2}
\]

\[
\varphi=\operatorname{atan2}(V,U)
\]

### 结果校验

四种表示必须满足 $G=U+jV=Ae^{j\varphi}$。

### 易错点

- 用 $\arctan(V/U)$ 丢失象限。

!!! tip "由本题补入知识库"
    补充：实虚表示适合画 Nyquist，模相表示适合正弦稳态与 Bode。

## EX-C4-04｜习题 4-4：一阶系统的正弦稳态输出 { #ex-c4-04 }

**题意摘要**

对 $G(s)=2/(0.25s+1)$ 和给定余弦输入，求稳态输出。

**对应知识点**

`C4.1`；母题 `Q-C4-01`。

**来源定位**

习题解印刷页 47–48（PDF p.53–54）。

### 解析路线

1. 读取输入幅值、角频率和初相位。
2. 计算 $A(\omega)$ 与 $\varphi(\omega)$。
3. 输出幅值乘以 $A$，相位相加。

### 关键公式

\[
y_{ss}(t)=A_i|G(j\omega)|\cos[\omega t+\phi_i+\angle G(j\omega)]
\]

### 结果校验

习题解得到输出幅值 $25\sqrt2/2$，相位约 $-75^\circ$。

### 易错点

- 把瞬态项也写进“稳态输出”。

!!! tip "由本题补入知识库"
    补充：稳定 LTI 系统对单频正弦的稳态输出仍为同频正弦。

## EX-C4-05｜习题 4-5：由谐振指标反求系统参数与带宽 { #ex-c4-05 }

**题意摘要**

已知二阶闭环谐振峰值和谐振频率，反求阻尼比、自然频率及开环参数，并估算带宽。

**对应知识点**

`C4.7`；母题 `Q-C4-06`。

**来源定位**

习题解印刷页 48–49（PDF p.54–55）。

### 解析路线

1. 由 $M_r$ 反求 $\zeta$。
2. 由 $\omega_r=\omega_n\sqrt{1-2\zeta^2}$ 求 $\omega_n$。
3. 由闭环标准式与开环 $K/[s(Ts+1)]$ 对比求 $K,T$，再求带宽。

### 关键公式

\[
M_r=\frac{1}{2\zeta\sqrt{1-\zeta^2}}
\]

\[
\omega_r=\omega_n\sqrt{1-2\zeta^2}
\]

### 结果校验

习题解得到约 $\omega_n=31.65,\zeta=0.5,K=31.65,T=0.0316$，带宽约 $22.38\,\mathrm{rad/s}$。

### 易错点

- $\zeta\ge1/\sqrt2$ 时仍套谐振峰公式。

!!! tip "由本题补入知识库"
    补充：出现明显谐振峰要求 $\zeta<1/\sqrt2$。

## EX-C4-06｜习题 4-6：由五幅渐近 Bode 图反求传递函数 { #ex-c4-06 }

**题意摘要**

根据低频斜率、转折频率和斜率变化，写出五个最小相位系统的开环传递函数。

**对应知识点**

`C4.3`、`C4.4`；母题 `Q-C4-04`。

**来源定位**

习题解印刷页 49–50（PDF p.55–56）。

### 解析路线

1. 由低频斜率确定原点极点/零点数。
2. 每次斜率变化 $\pm20\,\mathrm{dB/dec}$ 对应一阶零/极点，$\pm40$ 对应二阶。
3. 用已知幅值截距求增益，整理成时间常数因子。

### 关键公式

\[
20\log_{10}|G(j\omega)|
\]

### 结果校验

习题解分别给出含积分、惯性、振荡和零点的五个因式分解结果。

### 易错点

- 把转折频率写成时间常数本身。
- 只凭幅值图判断非最小相位零点。

!!! tip "由本题补入知识库"
    补充：幅值图只能确定最小相位模型；右半平面零点需相位或先验信息。

## EX-C4-07｜习题 4-7：增益变化对截止频率与精度的影响 { #ex-c4-07 }

**题意摘要**

根据给定 Bode 渐近图，比较不同增益下截止频率、相角裕度和稳态精度。

**对应知识点**

`C4.3`、`C4.7`；母题 `Q-C4-03`。

**来源定位**

习题解印刷页 50（PDF p.56）。

### 解析路线

1. 增益变化只使幅值曲线竖直平移。
2. 重新寻找 0 dB 交叉频率并在该频率读取相位。
3. 用低频增益/型别判断稳态误差变化。

### 结果校验

习题解指出增益由 12.5 增至 25 时截止频率升高、动态更快，但相角裕度减小。

### 易错点

- 认为增益变化会改变相位曲线。

!!! tip "由本题补入知识库"
    补充：增益是最简单的速度—稳定裕度—稳态精度权衡旋钮。

## EX-C4-08｜习题 4-8：四个系统的 Bode 图 { #ex-c4-08 }

**题意摘要**

对四个含积分、惯性、零点和二阶环节的系统画对数幅频与相频曲线。

**对应知识点**

`C4.3`；母题 `Q-C4-03`。

**来源定位**

习题解印刷页 50–51（PDF p.56–57）。

### 解析路线

1. 标准因式分解并列出转折频率。
2. 从低频起累计斜率，画渐近幅值。
3. 按因子叠加相位并在关键频率做精确点修正。

### 结果校验

习题解给出图 4.3—4.6；各图的最终斜率等于零点数减极点数乘 20 dB/dec。

### 易错点

- 相位曲线在转折频率处瞬间跳变。

!!! tip "由本题补入知识库"
    补充：相位近似通常在转折频率前后两个十倍频程内平滑变化。

## EX-C4-09｜习题 4-9：不同时间常数次序下的 Nyquist 轨迹 { #ex-c4-09 }

**题意摘要**

分析 $K(s+T_z^{-1})/[s(T_1s+1)(T_2s+1)]$ 在两组时间常数关系下的 Nyquist 图。

**对应知识点**

`C4.2`、`C5.4`；母题 `Q-C4-02`。

**来源定位**

习题解印刷页 51–53（PDF p.57–59）。

### 解析路线

1. 求 $\omega\to0$ 与 $\omega\to\infty$ 的起终方向。
2. 令虚部或实部为零求与坐标轴交点。
3. 根据时间常数次序判断轨迹是否穿越实轴/虚轴并标频率方向。

### 结果校验

习题解分别得到有实轴交点与无对应交点的两类轨迹。

### 易错点

- 只画正频段却不说明共轭对称补全。

!!! tip "由本题补入知识库"
    补充：Nyquist 轨迹拓扑可由低高频极限与轴交点先确定，再补中间形状。

## EX-C4-10｜习题 4-10：一阶超前环节的频率特性 { #ex-c4-10 }

**题意摘要**

由微分方程 $T\dot x_o+x_o=\dot u+u$ 求对数频率特性与极坐标图。

**对应知识点**

`C4.2`、`C4.3`；母题 `Q-C4-02`。

**来源定位**

习题解印刷页 53（PDF p.59）。

### 解析路线

1. 零初值拉氏变换求 $G(s)=(s+1)/(Ts+1)$。
2. 分别画零点和极点的 Bode 贡献。
3. 用起终点和相角符号画 Nyquist。

### 关键公式

\[
G(s)=\frac{s+1}{Ts+1}
\]

### 结果校验

习题解按 $T$ 的相对大小给出两类 Nyquist 轨迹和 Bode 形状。

### 易错点

- 忽略导数输入对应分子零点。

!!! tip "由本题补入知识库"
    补充：零点先于极点时产生相位超前，极点先于零点时产生相位滞后。

## EX-C4-11｜习题 4-11：Bode 曲线与网络/滤波类型配对 { #ex-c4-11 }

## EX-C4-12｜习题 4-12：六个传递函数与 Nyquist 图配对 { #ex-c4-12 }

**题意摘要**

把六个开环传递函数与六条 Nyquist 轨迹匹配。

**对应知识点**

`C4.2`、`C4.4`；母题 `Q-C4-02`。

**来源定位**

习题解印刷页 54–55（PDF p.60–61）。

### 解析路线

1. 按原点极点数确定低频起点方向。
2. 按相对阶次确定高频终点方向。
3. 利用实轴交点、右半平面零点和积分数区分相似曲线。

### 结果校验

习题解给出六组一一对应关系。

### 易错点

- 忽略右半平面零点造成的相位反常。

!!! tip "由本题补入知识库"
    补充：Nyquist 配对最有效的特征是“起点—终点—轴交点—方向”四元组。

## EX-C4-14｜习题 4-14：闭环谐振峰、谐振频率与带宽 { #ex-c4-14 }

**题意摘要**

由给定闭环频率响应求谐振指标与带宽。

**对应知识点**

`C4.7`；母题 `Q-C4-06`。

**来源定位**

习题解印刷页 55–56（PDF p.61–62）。

### 解析路线

1. 把闭环函数标准化为二阶形式。
2. 由分母系数求 $\zeta,\omega_n$。
3. 计算 $M_r,\omega_r$ 与带宽，或直接解 $|\Phi(j\omega_b)|=1/\sqrt2$。

### 结果校验

习题解给出 $\omega_n=\sqrt5,\zeta=1/\sqrt5,M_r=1.25,\omega_r\approx1.73$，带宽约 $2.97\,\mathrm{rad/s}$。

### 易错点

- 把开环 0 dB 截止频率当闭环带宽。

!!! tip "由本题补入知识库"
    补充：闭环带宽定义在闭环幅值相对低频值下降 3 dB 处。

## EX-C4-16｜习题 4-16：单位反馈系统的截止频率与相角 { #ex-c4-16 }

**题意摘要**

对开环 $1/[s(s+1)]$ 求增益交叉频率及该处相角。

**对应知识点**

`C4.3`、`C5.7`；母题 `Q-C5-07`。

**来源定位**

习题解印刷页 58（PDF p.64）。

### 解析路线

1. 解 $|G(j\omega_c)|=1$。
2. 代入求 $\angle G(j\omega_c)$。

\[
|G(j\omega_c)|=1
\]

习题解得到 $\omega_c\approx0.68\,\mathrm{rad/s}$，相角约 $-158.4^\circ$。

### 易错点

- 把相角裕度与相角本身混写。

!!! tip "由本题补入知识库"
    补充：相角裕度为 $180^\circ+\angle G(j\omega_c)$。

## EX-C4-17｜习题 4-17：由谐振峰与谐振频率设计参数 { #ex-c4-17 }

**题意摘要**

在单位反馈二阶结构中选择 $K,a$ 满足给定 $M_r$ 与 $\omega_r$，并求带宽。

**对应知识点**

`C4.7`；母题 `Q-C4-06`。

**来源定位**

习题解印刷页 58–59（PDF p.64–65）。

### 解析路线

1. 写闭环函数并识别 $\omega_n=\sqrt K$、$\zeta=a/(2\sqrt K)$。
2. 联立谐振峰和谐振频率方程。
3. 代回计算带宽并检查 $\zeta<1/\sqrt2$。

### 结果校验

习题解得到约 $K=485.8,a=26.5$，带宽约 $25.63\,\mathrm{rad/s}$。

### 易错点

- 只用一个谐振指标就试图确定两个参数。

!!! tip "由本题补入知识库"
    补充：两个独立频域指标可反求两个二阶参数。
