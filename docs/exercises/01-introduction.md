## EX-C1-01｜习题 1-1：开环、闭环与反馈作用辨析 { #ex-c1-01 }

**题意摘要**

把若干控制情形按开环/闭环分类，并判断反馈信号、反馈作用及控制强弱。

**对应知识点**

`C1.2`；母题 `Q-C1-01`。

**来源定位**

习题解印刷页 1（PDF p.7）。

### 解析路线

1. 先找被控量与给定量。
2. 检查输出信息是否返回比较点并改变控制作用；只有形成这一闭合因果链才是闭环。
3. 根据返回信号与给定信号的相减/相加关系判断负反馈或正反馈，并说明反馈对误差、抗扰和稳定风险的影响。

### 关键公式

\[
e(t)=r(t)-b(t)
\]

\[
\Phi(s)=\frac{G(s)}{1+G(s)H(s)}
\]

### 结果校验

习题解给出的选择结果为：(1)闭环，(2)都有，(3)都强，(4)闭环—更振荡。

### 易错点

- 把“有传感器”直接等同于闭环。
- 只说闭环精度高，却不提可能失稳。

!!! tip "由本题补入知识库"
    补充：判断闭环的充分证据是“输出信息返回并参与控制量形成”，而不是设备名称。

## EX-C1-02｜习题 1-2：开环与闭环系统优缺点比较 { #ex-c1-02 }

**题意摘要**

从结构、精度、抗扰、成本和稳定风险五个角度比较两类系统。

**对应知识点**

`C1.2`；母题 `Q-C1-03`。

**来源定位**

习题解印刷页 1（PDF p.7）。

### 解析路线

1. 先写开环：结构简单、稳定性通常易保证，但无法自动修正对象变化与扰动。
2. 再写闭环：利用误差反馈提高精度和抗扰能力，但增加元件、调试与稳定性设计要求。
3. 最后指出评价必须结合具体指标，不能抽象地说“闭环永远更好”。

### 结果校验

答案表以“简单/精度较低”对“较复杂/抗干扰能力强”等为主要对照。

### 易错点

- 把“稳定”与“稳态精度”混成同一个概念。

!!! tip "由本题补入知识库"
    补充：反馈的价值和代价应同时评价，形成性能—复杂度—鲁棒性的三方权衡。

## EX-C1-03｜习题 1-3：工程系统功能方块图抽象 { #ex-c1-03 }

**题意摘要**

将五个日常或机械系统从实物描述抽象为给定、控制、执行、对象、检测和输出等功能环节。

**对应知识点**

`C1.2`、`C1.3`；母题 `Q-C1-02`。

**来源定位**

习题解印刷页 1–2（PDF p.7–8）。

### 解析路线

1. 沿能量流确定执行元件与被控对象。
2. 沿信息流确定给定、比较、控制器和检测元件。
3. 按功能而不是设备名称画块，统一信号方向并标出反馈极性。

### 结果校验

习题解分别给出汽车速度、电炉温度、声控灯、轮船航向与路灯控制的功能方块图。

### 易错点

- 把执行元件与被控对象合并后丢失动力链。
- 方块图中同时混用物理量和设备名称却不标信号。

!!! tip "由本题补入知识库"
    补充：同一设备在不同边界选取下可能属于执行元件或对象，必须先声明系统边界。

## EX-C1-04｜习题 1-4：记录笔位置随动系统分析 { #ex-c1-04 }

**题意摘要**

识别记录笔装置的被控对象、输入、输出和反馈，并画规范功能方块图。

**对应知识点**

`C1.2`、`C1.3`；母题 `Q-C1-02`。

**来源定位**

习题解印刷页 2–3（PDF p.8–9）。

### 解析路线

1. 将输入电压换算为期望笔位移，将实际笔位移作为输出。
2. 识别电位计形成的位置反馈，比较后的电压经放大器和电动机驱动记录笔。
3. 说明位置误差改变驱动方向，直到误差趋近于零。

### 关键公式

\[
e_u(t)=u_i(t)-u_f(t)
\]

### 结果校验

核心回路为“输入—比较—放大—电机—齿轮/记录笔—位置反馈”。

### 易错点

- 把记录纸运动当作本回路的被控量。
- 反馈方向没有通过“误差变小”验证。

!!! tip "由本题补入知识库"
    补充：画方块图后应做符号实验——假设笔偏小，检查控制作用是否把它推向给定值。

## EX-C1-05｜习题 1-5：水箱液位开环与闭环控制 { #ex-c1-05 }

**题意摘要**

比较人工阀门调节和液位检测反馈两种水箱控制结构，并解释扰动下的差异。

**对应知识点**

`C1.2`；母题 `Q-C1-01`。

**来源定位**

习题解印刷页 3–4（PDF p.9–10）。

### 解析路线

1. 将进水阀开度作为操纵量，液位作为被控量，出水变化作为主要扰动。
2. 开环图只保留操作者/阀门—水箱链；闭环图增加液位检测、比较与执行机构。
3. 用出水流量突然变化说明闭环如何自动修正，开环为何产生持续偏差。

### 结果校验

习题解分别给出人工开环和电机驱动阀门的闭环方块图。

### 易错点

- 把出水流量写成给定量。
- 不区分测量反馈与操作者观察反馈。

!!! tip "由本题补入知识库"
    补充：扰动注入位置决定扰动到输出的传递通道，后续误差分析会再次使用这一结构。

## EX-C1-06｜习题 1-6：离心调速器功能方块图 { #ex-c1-06 }

**题意摘要**

将机械离心调速器抽象为转速给定、离心测量、比较/杠杆、燃料阀、发动机和负载扰动构成的闭环。

**对应知识点**

`C1.2`、`C1.3`；母题 `Q-C1-05`。

**来源定位**

习题解印刷页 4（PDF p.10）。

### 解析路线

1. 把飞球位移视为转速测量信号。
2. 把弹簧预紧或给定机构视为转速给定。
3. 由转速偏差经杠杆改变燃料流量，检查负载增大时控制作用是否增加驱动力矩。

### 结果校验

习题解的主链为“给定—调速机构—燃料开关—发动机—转速”，并由转速经离心机构反馈。

### 易错点

- 把飞球当作控制器而忽略其测量功能。
- 未把负载转矩作为扰动标入对象端。

!!! tip "由本题补入知识库"
    补充：机械反馈与电反馈在结构上等价，分析时可统一为比较点和反馈环节。
