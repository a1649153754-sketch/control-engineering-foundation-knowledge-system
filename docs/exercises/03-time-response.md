## EX-C3-01｜习题 3-1：RC 系统对双阶跃输入的响应 { #ex-c3-01 }

**题意摘要**

将“在两个时刻发生变化”的电压输入写成双阶跃，求一阶系统输出。

**对应知识点**

`C3.1`、`C3.2`；母题 `Q-C3-01`。

**来源定位**

习题解印刷页 27（PDF p.33）。

### 解析路线

1. 由电路求 $G(s)=1/(RCs+1)$。
2. 把输入写成 $A u(t)-B u(t-t_0)$。
3. 分别求一阶阶跃响应并作时移叠加。

### 关键公式

\[
x_o(t)=AK(1-e^{-t/T})u(t)-BK(1-e^{-(t-t_0)/T})u(t-t_0)
\]

### 结果校验

习题解取 $T=4\,\mathrm{s}$，在第二次开关后由前一时刻状态连续过渡。

### 易错点

- 第二段响应从零重新起算，破坏电容电压连续性。

!!! tip "由本题补入知识库"
    补充：分段输入的响应可由零状态叠加得到，状态连续性是额外校验。

## EX-C3-02｜习题 3-2：含零点二阶系统的阶跃响应 { #ex-c3-02 }

**题意摘要**

对 $G(s)=(2s+1)/(s^2+5s+6)$ 求单位阶跃响应。

**对应知识点**

`C3.1`、`C3.3`；母题 `Q-C3-03`。

**来源定位**

习题解印刷页 27（PDF p.33）。

### 解析路线

1. 乘以 $1/s$ 得输出变换。
2. 做部分分式，保留零点对各模态系数的影响。
3. 反演并检查初值、终值。

### 结果校验

结果为常值与两个衰减指数的组合；稳态值等于 $G(0)$。

### 易错点

- 只看分母按“标准二阶”套公式，忽略零点。

!!! tip "由本题补入知识库"
    补充：极点决定模态，零点决定模态权重，二者共同决定波形。

## EX-C3-03｜习题 3-3：带初值与开关切换的 RC 响应 { #ex-c3-03 }

**题意摘要**

分析电容具有初始电压、开关在指定时刻切换后的输出。

**对应知识点**

`C3.1`、`C3.2`；母题 `Q-C3-01`。

**来源定位**

习题解印刷页 27–28（PDF p.33–34）。

### 解析路线

1. 分别建立切换前后的一阶电路模型。
2. 用电容电压连续条件确定切换后初值。
3. 写完整分段响应并检查每个区间终值。

### 结果校验

习题解的响应由一个常值、一个衰减指数和延迟项组成。

### 易错点

- 切换时电容电压突变。
- 把切换前后的时间常数混用。

!!! tip "由本题补入知识库"
    补充：开关系统宜采用“分区模型 + 边界状态连续”而不是一个全局传递函数。

## EX-C3-04｜习题 3-4：时变时间常数系统的分段响应 { #ex-c3-04 }

**题意摘要**

对时间常数随机构位置变化的一阶系统画方块图、求传递关系并计算多个时刻输出。

**对应知识点**

`C3.2`、`C3.7`；母题 `Q-C3-02`。

**来源定位**

习题解印刷页 28–29（PDF p.34–35）。

### 解析路线

1. 由几何/机构关系得到时间常数 $T$。
2. 在每个固定参数区间按一阶系统处理。
3. 切换点以上一段终值作为新初值，逐段递推。

### 关键公式

\[
y(t)=y_\infty+[y(t_0)-y_\infty]e^{-(t-t_0)/T}
\]

### 结果校验

习题解给出 $T=4\,\mathrm{s}$，并列出若干时刻响应与分段曲线。

### 易错点

- 每段都从零初始响应开始。
- 参数变化时仍使用单一 LTI 传递函数。

!!! tip "由本题补入知识库"
    补充：分段常参数近似是处理慢变/切换对象的基本工程方法。

## EX-C3-05｜习题 3-5：一型一阶闭环的阶跃与脉冲响应 { #ex-c3-05 }

**题意摘要**

由开环 $4/[s(s+5)]$ 构成单位反馈，求阶跃和脉冲响应。

**对应知识点**

`C3.1`、`C3.2`；母题 `Q-C3-01`。

**来源定位**

习题解印刷页 29–30（PDF p.35–36）。

### 解析路线

1. 先闭环化简得到 $\Phi(s)$。
2. 分别乘 $1/s$ 或 1。
3. 部分分式反演，并利用脉冲响应为阶跃响应导数核对。

### 关键公式

\[
\Phi(s)=\frac{G(s)}{1+G(s)}
\]

\[
g(t)=\frac{d}{dt}h(t)
\]

### 结果校验

闭环分母为二阶；阶跃终值为 1。

### 易错点

- 直接使用开环函数求输出。

!!! tip "由本题补入知识库"
    补充：单位反馈的闭环响应必须先由 $G$ 转为 $\Phi$。

## EX-C3-06｜习题 3-6：按阻尼比选择闭环增益 { #ex-c3-06 }

**题意摘要**

对单位反馈 $K/[s(0.1s+1)]$，选择增益使阻尼比为 0.5。

**对应知识点**

`C3.3`、`C3.5`；母题 `Q-C3-05`。

**来源定位**

习题解印刷页 30（PDF p.36）。

### 解析路线

1. 写闭环特征式。
2. 归一化为 $s^2+2\zeta\omega_ns+\omega_n^2$。
3. 比较系数联立求 $K$。

### 关键公式

\[
0.1s^2+s+K=0
\]

### 结果校验

习题解得到 $K=10$。

### 易错点

- 未把最高次系数归一化就读 $\zeta,\omega_n$。

!!! tip "由本题补入知识库"
    补充：增益同时改变 $\omega_n$ 与 $\zeta$，并非只改变速度。

## EX-C3-07｜习题 3-7：二阶闭环指标及增益影响 { #ex-c3-07 }

**题意摘要**

分析单位反馈 $K/[s(s+1)]$ 的上升、峰值、超调与调整时间，并讨论 $K$ 变化。

**对应知识点**

`C3.3`、`C3.4`；母题 `Q-C3-04`。

**来源定位**

习题解印刷页 30–32（PDF p.36–38）。

### 解析路线

1. 化为标准二阶式，得到 $\omega_n=\sqrt K$、$\zeta=1/(2\sqrt K)$。
2. 按 $K$ 判断过阻尼、临界、欠阻尼区间。
3. 欠阻尼时套用 $M_p,t_p,t_s$，最后分析随 $K$ 的单调趋势。

### 关键公式

\[
M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}
\]

\[
t_p=\frac{\pi}{\omega_n\sqrt{1-\zeta^2}}
\]

### 结果校验

习题解指出 $K$ 增大时 $t_p$、$t_r$ 变小，而 $M_p$ 增大；5% 调整时间在该模型中为常数 6 s。

### 易错点

- 忽略 $K\le1/4$ 时不再欠阻尼。

!!! tip "由本题补入知识库"
    补充：同一参数可能改善速度却恶化超调，设计应看指标集合。

## EX-C3-08｜习题 3-8：由二阶微分方程求最大超调 { #ex-c3-08 }

**题意摘要**

把二阶微分方程与标准式比较，求单位阶跃响应最大超调。

**对应知识点**

`C3.3`、`C3.4`；母题 `Q-C3-04`。

**来源定位**

习题解印刷页 32（PDF p.38）。

### 解析路线

1. 拉氏变换求传递函数。
2. 归一化分母并读出 $\zeta$。
3. 确认 $0<\zeta<1$ 后计算 $M_p$。

### 关键公式

\[
M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}
\]

### 结果校验

结果由阻尼比唯一决定，与输入幅值无关（以百分比计）。

### 易错点

- 把最大超调量和最大超调百分比混用。

!!! tip "由本题补入知识库"
    补充：超调百分比是归一化指标，实际峰值还要乘稳态值。

## EX-C3-09｜习题 3-9：由峰值时间与调整时间反求二阶参数 { #ex-c3-09 }

**题意摘要**

由 5% 调整时间和峰值时间求阻尼比与自然频率。

**对应知识点**

`C3.4`、`C3.5`；母题 `Q-C3-05`。

**来源定位**

习题解印刷页 32（PDF p.38）。

### 解析路线

1. 使用 $t_s\approx3/(\zeta\omega_n)$。
2. 使用 $t_p=\pi/(\omega_n\sqrt{1-\zeta^2})$。
3. 联立求解并检查 $0<\zeta<1$。

### 结果校验

习题解给出约 $\zeta=0.69,\ \omega_n=2.2\,\mathrm{rad/s}$。

### 易错点

- 把 2% 误差带的系数 4 代入 5% 条件。

!!! tip "由本题补入知识库"
    补充：反求题首先要确认采用的调整时间定义。

## EX-C3-10｜习题 3-10：并联零点对阶跃响应的影响 { #ex-c3-10 }

**题意摘要**

对由两个一阶通道并联形成、含零点的系统求阶跃响应并分析零点影响。

**对应知识点**

`C3.3`、`C3.5`；母题 `Q-C3-06`。

**来源定位**

习题解印刷页 32–33（PDF p.38–39）。

### 解析路线

1. 合并并联传递函数并确定极点、零点。
2. 乘阶跃输入后部分分式。
3. 比较有无零点时模态系数和初始斜率。

### 结果校验

习题解得到两个指数模态的线性组合；零点改变响应形状但不改变并联后的极点位置。

### 易错点

- 仅从极点判断波形而忽略分子。

!!! tip "由本题补入知识库"
    补充：零点靠近主导极点时会显著改变留数，不能只用二阶极点指标。

## EX-C3-11｜习题 3-11：速度反馈满足指定二阶参数 { #ex-c3-11 }

**题意摘要**

为带速度反馈的单位反馈系统选反馈系数，使闭环阻尼比与自然频率达到给定值。

**对应知识点**

`C3.3`、`C3.5`；母题 `Q-C3-05`。

**来源定位**

习题解印刷页 33（PDF p.39）。

### 解析路线

1. 先化简含速度反馈的特征方程。
2. 与标准二阶式比较两个系数。
3. 解出反馈参数并检查增益/极性。

习题解由目标 $\zeta=0.5,\omega_n=3.16$ 求得 $K_v\approx0.216$。

!!! tip "由本题补入知识库"

## EX-C3-12｜习题 3-12：复平面性能约束区域 { #ex-c3-12 }

**题意摘要**

根据阻尼比与阻尼自然频率约束，在 $s$ 平面画出允许极点区域。

**对应知识点**

`C3.3`、`C3.4`；母题 `Q-C3-05`。

**来源定位**

习题解印刷页 33–34（PDF p.39–40）。

### 解析路线

1. 把等阻尼比写成从原点出发的射线。
2. 把 $\zeta\omega_n=-\Re(s)$ 约束写成竖直边界。
3. 取各不等式交集并标明边界是否包含。

### 关键公式

\[
\zeta=-\frac{\sigma}{\sqrt{\sigma^2+\omega^2}}
\]

### 结果校验

习题解给出四种阴影区域，对应不同不等式方向。

### 易错点

- 只画一条等阻尼线而忘记上下共轭区域。

!!! tip "由本题补入知识库"
    补充：极点几何约束是根轨迹设计与时域指标的桥梁。

## EX-C3-16｜习题 3-16：扭转弹簧—阻尼—惯量系统响应 { #ex-c3-16 }

**题意摘要**

对转动惯量、扭簧与阻尼组成的二阶系统施加阶跃转矩，求角位移响应。

**对应知识点**

`C3.3`、`C3.4`；母题 `Q-C3-04`。

**来源定位**

习题解印刷页 36（PDF p.42）。

### 解析路线

1. 列转矩平衡并求传递函数。
2. 读出 $\omega_n=\sqrt{k/J}$、$\zeta=D/(2\sqrt{kJ})$。
3. 按阻尼类型写响应。

### 关键公式

\[
\frac{\Theta(s)}{M_i(s)}=\frac{1/J}{s^2+(D/J)s+k/J}
\]

### 结果校验

习题解给出欠阻尼单位阶跃形式，并明确峰值、调整指标可由标准二阶式求。

## EX-C3-21｜习题 3-21：加速度计参数变化与阻尼 { #ex-c3-21 }
