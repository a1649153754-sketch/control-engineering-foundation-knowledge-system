## C5.1 系统稳定性的基本概念

**学习目标**：理解外部稳定、内部稳定、渐近稳定和有界输入有界输出稳定的基本含义。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目要求判断稳定概念，或从响应、极点和状态行为解释稳定。 |
| 主方法 | 先明确研究对象是零输入状态、输入输出还是平衡点；再选择相应稳定定义。 |
| 核心关系 | 线性定常最小实现中，BIBO 稳定与传递函数所有极点位于左半平面相对应。 |
| 失效边界 | 零极点相消可能掩盖内部不稳定模态；传递函数输入输出稳定不总能代表内部全部状态稳定。 |
| 达标证据 | 能用极点、脉冲响应和状态三个角度解释稳定。 |
| 标签 | 稳定概念 · BIBO · 内部稳定 |

**学习目标**：掌握连续线性系统稳定的充要条件及特征方程与闭环极点的联系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给闭环传递函数或系统矩阵，要求给出稳定条件。 |
| 主方法 | 先构造闭环特征方程，检查是否有右半平面或虚轴极点；对状态模型检查矩阵 $A$ 特征值。 |

| 达标证据 | 能从特征方程、极点图和时间响应相互验证稳定性。 |

**学习目标**：掌握 Routh（劳斯）代数稳定性判据，包括参数范围、零首项和全零行特殊情况。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 高阶特征多项式不便求根，要求判断右半平面根数或参数稳定区间。 |
| 主方法 | 按降幂排列系数构造 Routh 表；首列符号变化次数等于右半平面根数；参数题转化为首列同号不等式。 |

## C5.4 乃奎斯特稳定性判据

**学习目标**：掌握 Nyquist 稳定判据，理解开环右半平面极点、绕点次数和闭环不稳定极点数之间的关系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给出开环频率特性或 Nyquist 图，要求闭环稳定性、增益范围或临界点。 |
| 主方法 | 先确定开环右半平面极点数 $P$，按统一方向约定统计对 $-1+j0$ 的环绕数，再由辩值原理求闭环右半平面零点数。 |
| 核心关系 | 按所采用方向约定使用 $Z=P-N$ 或等价形式；关键是从始至终保持环绕方向与符号一致。 |
| 失效边界 | 不要只看是否经过 $-1$；必须考虑完整 Nyquist 轮廓、虚轴极点绕行和开环不稳定极点。 |
| 达标证据 | 能对含积分环节或开环不稳定极点的系统完成 Nyquist 稳定判断。 |
| 标签 | Nyquist判据 · 辩值原理 · 开环不稳定 |

## C5.5 应用乃奎斯特稳定性判据分析延时系统的稳定性

**学习目标**：会把纯延迟引入频域相位，并用 Nyquist 判据分析延时系统稳定边界。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 系统含 $e^{-\tau s}$，要求最大允许延迟、临界频率或稳定性。 |
| 主方法 | 延迟不改幅值、增加相位滞后 $-\omega\tau$；先找幅值为 1 的频率，再使相位达到临界条件求 $\tau$。 |
| 核心关系 | $e^{-j\omega\tau}$ 的幅值为 1，相位为 $-\omega\tau$。 |
| 失效边界 | 不能把纯延迟当作普通一阶惯性；Pade 近似只是在有限频段内的有理近似。 |
| 达标证据 | 能求一个简单系统的临界延迟，并说明延迟为何降低相位裕度。 |
| 标签 | 延迟系统 · 纯滞后 · 稳定边界 |

## C5.6 由伯德图判断系统的稳定性

**学习目标**：掌握由 Bode 图判断闭环稳定性及增益裕度、相位裕度的读法。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给开环 Bode 图，要求稳定性、穿越频率或参数变化后的裕度。 |
| 主方法 | 找增益交叉频率 $\omega_c$ 和相位交叉频率 $\omega_g$；读取相位裕度和增益裕度，并结合开环极点情况判断。 |
| 核心关系 | $\gamma=180^\circ+\angle L(j\omega_c)$；$K_g=1/\lvert L(j\omega_g)\rvert$（或分贝形式）。 |
| 失效边界 | 对开环不稳定或多次交叉系统，简单“正裕度即稳定”可能不够，需回到 Nyquist 全局判断。 |
| 达标证据 | 能从 Bode 图准确标注交叉频率和两种裕度。 |
| 标签 | Bode稳定 · 相位裕度 · 增益裕度 |

## C5.7 控制系统的相对稳定性

**学习目标**：理解相对稳定性，用稳定裕度、极点离虚轴距离和阻尼指标评价“离失稳还有多远”。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 系统虽稳定但响应振荡或对参数敏感，要求比较稳定程度。 |
| 主方法 | 综合看相位裕度、增益裕度、闭环阻尼比、灵敏度峰值和主导极点位置。 |
| 核心关系 | 绝对稳定回答“是否稳定”；相对稳定回答“稳定得多稳、鲁棒余量多大”。 |
| 失效边界 | 单一裕度不能覆盖所有不确定性；裕度大也不自动保证时域每项指标都好。 |
| 达标证据 | 能比较两个稳定系统的相对稳定性并解释所选指标。 |
| 标签 | 相对稳定 · 鲁棒性 · 稳定裕度 |
