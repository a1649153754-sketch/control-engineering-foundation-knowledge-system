# 个人高频疑问挂接

> 这一页来自既往学习中的反复疑问，是个性化导航层，不属于教材目录。每个问题都挂回教材节点，后续遇到新题时继续更新同一节点。

| 疑问 ID | 问题 | 关联节点 | 当前处理原则 |
| --- | --- | --- | --- |
| J-C-01 | 看到 Bode 图怎样快速识别系统环节和转折频率？ | C4.3/C4.4 | 先看低频斜率与截距，再按每次 ±20 dB/dec 的斜率变化识别一阶零极点，最后用相位校核。 |
| J-C-02 | 共振频率、共振峰值与阻尼比之间如何精确联系？ | C3.3/C3.4/C4.7 | 先确认标准二阶和 $\zeta<1/\sqrt{2}$，再使用二阶频响公式；不满足条件时直接求幅值极值。 |
| J-C-03 | 给定相位裕度、超调量或带宽，怎样反求增益 K？ | C5.6/C7.1/C7.5 | 把指标换成目标 $\zeta$、$\omega_c$ 或相位条件，解幅值交叉条件，再对闭环指标复核。 |
| J-C-04 | Kp、Ki 固定或受约束时，控制器还能怎样设计？ | C7.2/C7.3/C7.4/C7.7 | 把不可调参数视为对象的一部分，优先调整其余零极点、反馈结构或工作频段，而非强行套标准 PID 表。 |
| J-C-05 | 根轨迹有没有适合手算的精确做法？ | C8.1/C8.2/C8.4 | 用相角条件判点、幅值条件求参数；分离点和虚轴交点分别由导数与 Routh 得到，图形只承担组织信息。 |
| J-C-06 | 靠近主导极点的零极点为什么一般不能随意相消？ | C3.5/C8.5 | 响应由极点位置与留数共同决定；近主导区域的零点会显著改变模态系数和瞬态形状。 |
| J-C-07 | 右半平面极点或零点能否约分相消？ | C2.4/C5.1/C5.2 | 输入输出表达式的形式相消不保证内部稳定或鲁棒实现；右半平面模态尤其不能作为安全设计手段。 |
| J-C-08 | 怎样从反馈结构反推出等效方块图和闭环传递函数？ | C1.2/C2.5/C7.4 | 先写每个比较点的信号方程，再局部化简内环，避免凭图形直觉漏掉反馈符号。 |
| J-C-09 | 动态刚度与普通静刚度、频率响应有什么联系？ | C4.8 | 动刚度是力/位移的频率函数，静刚度只是零频极限；共振附近必须考虑惯性和阻尼。 |
| J-C-10 | 为什么同一闭环极点位置的系统，阶跃曲线仍可能差很多？ | C3.5/C8.5 | 闭环零点、非主导极点和模态留数会改变初始方向、超调和各模态权重。 |
| J-C-11 | 非单位反馈下的稳态误差为什么不能直接套单位反馈公式？ | C6.1/C6.2 | 先定义物理输出误差，再从方块图推导误差传递函数；比较点误差信号与输出误差未必相同。 |
| J-C-12 | MATLAB/Simulink 得到曲线后，怎样判断结果有没有建模错误？ | C2.9/C3.6/C4.9/C7.8/C10.5 | 至少检查极点、直流增益、初值/终值、低高频极限、单位和步长；软件结果必须接受理论先验约束。 |

## 使用方法

1. 新问题先判断能否归入已有 `J-C` 节点。
2. 若只是参数变化，不新建节点；把题号和错因追加到记录表。
3. 只有出现新的概念边界或跨章连接，才新增编号。
