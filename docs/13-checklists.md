# 三级检查清单

> 共 385 项。每项都能落到一个稳定节点；勾选不是“看过”，而是已经给出可复核证据。

## 使用方法

- 第一次学习只勾 `a/b`：知道是什么、看到题能启动。
- 强化阶段勾 `c/d`：能写核心关系并主动查边界。
- 真题/综合阶段勾 `e`：能用题目、实验或脚本给证据。
