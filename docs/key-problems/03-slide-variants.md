## KP-S01｜讲义幻灯例1：三组极点与响应匹配 { #kp-s01 }

**题面要素（摘要）**

本页为 KP-A04 的讲义/幻灯变体：给A、B、C三个一/二阶系统的极点图与B的单位阶跃响应，要求画A、C响应并解释阻尼、速度与稳定性。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.41；与 `KP-A04` 为重复/讲义变体。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C3.3`, `C3.4`, `C3.5`；母题 `Q-C3-06`。

### 参考资料给出的路线

资料围绕“三组极点与响应匹配”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 把每组极点按实部、阻尼比、虚部和是否在右半平面分类。
2. 由最靠近虚轴且留数不小的极点估计衰减速度；由复极点角度判断振荡。
3. 检查是否存在不稳定极点、近原点实极点或高频快极点。
4. 将稳态增益、超调、振荡频率和调整时间逐项与曲线匹配。

### 复核清单

- 只看虚部判断快慢
- 忽略右半平面极点
- 把零点当极点读图

!!! tip "我的思考"
    这类匹配题应拆成四个互相独立的判据：稳不稳、终值多少、衰减多快、振荡多快。不要凭曲线“长得像”。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-S02｜讲义幻灯例2：速度环跟踪/扰动/二阶最优 { #kp-s02 }

**题面要素（摘要）**

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.41–42；与 `KP-A14` 为重复/讲义变体。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

### 参考资料给出的路线

资料围绕“速度环跟踪/扰动/二阶最优”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 把 PID 写成 Kd s+Kp+Ki/s，并明确期望系统型别。
2. 由目标闭环模型或系数匹配确定参数；若用频域法，分别分配低频积分和中频相位提升。
3. 检查闭环所有极点、稳态误差、超调、控制量和高频噪声。
4. 给出抗饱和、微分滤波及参数调整方向。

### 复核清单

- 三参数只做形式匹配不查稳定
- 积分饱和
- 微分放大噪声

!!! tip "我的思考"
    PID 不是三个旋钮各管一个指标。三项共同改变闭环特征多项式，调整时必须看耦合和控制器可实现性。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-S06｜讲义幻灯例6：Nyquist/Bode/裕度 { #kp-s06 }

**题面要素（摘要）**

本页为 KP-A06 的讲义/幻灯变体：单位负反馈开环 G(s)=200/[s(s+1)(s+20)]，用Nyquist判稳并求增益裕量，画渐近Bode、估截止频率与相位裕度。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.43–44；与 `KP-A06` 为重复/讲义变体。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 参考资料给出的路线

资料围绕“Nyquist/Bode/裕度”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 复核清单

- 不先数 P
- 环绕方向约定前后不一致
- 有多个交叉频率仍套单交叉结论

!!! tip "我的思考"
    Nyquist 不是画漂亮曲线，而是把“开环右半平面极点数”转成“闭环零点数”。曲线细节服务于拓扑计数。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-S12｜讲义幻灯例12：正频Nyquist补全 { #kp-s12 }

**题面要素（摘要）**

本页为 KP-A08 的讲义/幻灯变体：给最小相位系统正频Nyquist曲线和反馈系数H=2，补全全频曲线、判断闭环稳定并讨论开环增益估计。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.47；与 `KP-A08` 为重复/讲义变体。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 参考资料给出的路线

资料围绕“正频Nyquist补全”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 复核清单

- 不先数 P
- 环绕方向约定前后不一致
- 有多个交叉频率仍套单交叉结论

!!! tip "我的思考"
    Nyquist 不是画漂亮曲线，而是把“开环右半平面极点数”转成“闭环零点数”。曲线细节服务于拓扑计数。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。
