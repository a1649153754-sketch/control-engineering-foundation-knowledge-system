## KP-A01｜第一组例1：复杂多环方块图化简 { #kp-a01 }

**题面要素（摘要）**

多环方块图含环节 5s+0.2、4/(s²+s+2)、2.5、(s+2)/(s+10)，以及局部反馈2和外反馈0.4，要求化简为输入到输出传递函数。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.1。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C2.5`, `C2.6`；母题 `Q-C2-06`。

### 参考资料给出的路线

资料围绕“复杂多环方块图化简”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 标出所有比较点、分支点和信号方向，先确认正负号。
2. 优先化简最内层、互不耦合的反馈环；交叉环复杂时改用梅逊公式。
3. 移动比较点或分支点时同时补乘/除相应环节。
4. 最后用极端值（反馈置零、某环节置一）检查等效传递函数。

### 复核清单

- 比较点移动后漏因子
- 局部反馈符号看反
- 非接触回路判定错误

!!! tip "我的思考"
    复杂方块图不是“眼力题”。把它视为一组线性代数方程，任何化简都应能被方程回代验证。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.1–2。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

### 我的重构解法

1. 统一正方向和广义坐标，先画每个刚体/质量块的受力图或力矩图。
2. 用几何约束、杠杆比、齿轮比或丝杠导程把各点位移与速度折算到同一坐标。
3. 分别列牛顿第二定律或转动方程；弹簧、阻尼力必须写成相对位移与相对速度。
4. 在零初始条件下作拉氏变换，联立消元得到指定输入到输出的传递函数。
5. 用量纲、静态极限、高频阶次和极端参数退化检查结果。

### 数值/结论检查点

资料给出的核心结果为 \(V_2/F=(D_2s+k)/[(Ms+D_1)(ms^2+D_2s+k)+ms(D_2s+k)]\)。

### 复核清单

- 把绝对位移误写成相对位移
- 漏掉作用反作用力
- 杠杆/齿轮折算方向或平方关系错误

!!! tip "我的思考"
    这类题真正考的是“选坐标—写兼容条件—守住能量/量纲”。传递函数只是最后的消元结果。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

- 闭环零点影响被忽略

## KP-A06｜第一组例6：Nyquist判稳、Bode、截止频率和裕度 { #kp-a06 }

**题面要素（摘要）**

单位负反馈开环 G(s)=200/[s(s+1)(s+20)]，用Nyquist判稳并求增益裕量，画渐近Bode、估截止频率与相位裕度。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.5–7。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 参考资料给出的路线

资料围绕“Nyquist判稳、Bode、截止频率和裕度”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 数值/结论检查点

对 \(200/[s(s+1)(s+20)]\)：相位交叉 \(\omega_g=2\sqrt5\approx4.47\)，增益裕量约2.1；渐近估算 \(\omega_c\approx\sqrt{10}=3.16\)，相位裕量约8.5°。

### 复核清单

- 不先数 P
- 环绕方向约定前后不一致
- 有多个交叉频率仍套单交叉结论

!!! tip "我的思考"
    Nyquist 不是画漂亮曲线，而是把“开环右半平面极点数”转成“闭环零点数”。曲线细节服务于拓扑计数。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。
