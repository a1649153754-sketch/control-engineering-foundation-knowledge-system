## KP-B01｜第二组例1：机电—运放闭环系统传递函数 { #kp-b01 }

**题面要素（摘要）**

机电闭环系统由机械M-D-K对象和两个运放网络组成，要求各局部传函、总方块图及闭环U2/U1。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.27–28。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C2.5`, `C2.6`；母题 `Q-C2-06`。

### 参考资料给出的路线

资料围绕“机电—运放闭环系统传递函数”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 标出所有比较点、分支点和信号方向，先确认正负号。
2. 优先化简最内层、互不耦合的反馈环；交叉环复杂时改用梅逊公式。
3. 移动比较点或分支点时同时补乘/除相应环节。
4. 最后用极端值（反馈置零、某环节置一）检查等效传递函数。

### 复核清单

- 比较点移动后漏因子
- 局部反馈符号看反
- 非接触回路判定错误

!!! tip "我的思考"
    复杂方块图不是“眼力题”。把它视为一组线性代数方程，任何化简都应能被方程回代验证。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-B02｜第二组例2：五组极点与五条阶跃曲线匹配 { #kp-b02 }

**题面要素（摘要）**

五个静态增益为1的一/二阶环节，给极点图和J—N五条阶跃曲线，完成对应关系并写判断依据。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.29。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C3.3`, `C3.4`, `C3.5`；母题 `Q-C3-06`。

### 参考资料给出的路线

资料围绕“五组极点与五条阶跃曲线匹配”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 把每组极点按实部、阻尼比、虚部和是否在右半平面分类。
2. 由最靠近虚轴且留数不小的极点估计衰减速度；由复极点角度判断振荡。
3. 检查是否存在不稳定极点、近原点实极点或高频快极点。
4. 将稳态增益、超调、振荡频率和调整时间逐项与曲线匹配。

### 数值/结论检查点

资料按阻尼、实部和是否不稳定给出五组极点—曲线匹配表；核心判据是终值、超调、实部衰减和虚部振荡四项分离。

### 复核清单

- 只看虚部判断快慢
- 忽略右半平面极点
- 把零点当极点读图

!!! tip "我的思考"
    这类匹配题应拆成四个互相独立的判据：稳不稳、终值多少、衰减多快、振荡多快。不要凭曲线“长得像”。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

### 参考资料给出的路线

### 我的重构解法

1. 先求闭环传递函数并检查闭环稳定。
2. 归一化分母，识别一阶、标准二阶或高阶主导极点结构。

## KP-B04｜第二组例4：双环系统稳定与稳态误差 { #kp-b04 }

**题面要素（摘要）**

双环系统 G1=5、G2=3/(0.01s+1)、Gp=4/(0.1s+1)，判稳，求2t参考与0.1阶跃扰动共同作用的稳态误差，并给扰动零差条件。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.31–32。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C2.5`, `C5.1`, `C6.3`, `C7.4`；母题 `Q-C6-04`。

### 参考资料给出的路线

资料围绕“双环系统稳定与稳态误差”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 先从最内环开始化简，得到外环看到的等效对象。
2. 分别建立参考、扰动、测量反馈的传递通道。
3. 写闭环特征方程，用 Routh/Nyquist 检查稳定。
4. 对给定输入与扰动用终值定理求误差；若要求零误差，判断积分应放在哪个环节。

### 数值/结论检查点

资料先化内环，得到三阶特征方程并用Routh判稳；参考和扰动稳态误差分别求出后叠加。

### 复核清单

- 直接把多环视为一个单位反馈
- 内外环符号混淆
- 积分放错位置导致某通道仍有误差

!!! tip "我的思考"
    多环题要问“哪一个环路包住了哪一个扰动注入点”。积分是否有效，取决于它是否位于该通道的低频环路中。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-B05｜第二组例5：Nyquist、Bode与稳定裕度 { #kp-b05 }

**题面要素（摘要）**

单位负反馈开环 G(s)=50/[s(s+1)(s+20)]，完成Nyquist、增益裕量、Bode、截止频率与相位裕度。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.32–34。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 参考资料给出的路线

资料围绕“Nyquist、Bode与稳定裕度”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 数值/结论检查点

对 \(50/[s(s+1)(s+20)]\)：相位交叉约4.47rad/s，增益裕量约8.4；渐近估算交叉频率约1.58rad/s，相位裕量约27.8°。

### 复核清单

- 不先数 P
- 环绕方向约定前后不一致
- 有多个交叉频率仍套单交叉结论

!!! tip "我的思考"
    Nyquist 不是画漂亮曲线，而是把“开环右半平面极点数”转成“闭环零点数”。曲线细节服务于拓扑计数。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-B07｜第二组例7：PID整形成Ⅰ型二阶最优 { #kp-b07 }

**题面要素（摘要）**

对象40000/[(s+2)(s+10)(s+100)]，用PID整形成Ⅰ型二阶最优模型，并要求闭环阻尼比1。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.37–38。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C7.5`, `C7.6`, `C7.7`；母题 `Q-C7-06`。

### 参考资料给出的路线

资料围绕“PID整形成Ⅰ型二阶最优”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 把 PID 写成 Kd s+Kp+Ki/s，并明确期望系统型别。
2. 由目标闭环模型或系数匹配确定参数；若用频域法，分别分配低频积分和中频相位提升。
3. 检查闭环所有极点、稳态误差、超调、控制量和高频噪声。
4. 给出抗饱和、微分滤波及参数调整方向。

### 数值/结论检查点

资料通过Ⅰ型二阶最优匹配得到 \(K\approx1.25\)，并构造含两个零点和一个积分的PID。

### 复核清单

- 三参数只做形式匹配不查稳定
- 积分饱和
- 微分放大噪声

!!! tip "我的思考"
    PID 不是三个旋钮各管一个指标。三项共同改变闭环特征多项式，调整时必须看耦合和控制器可实现性。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。

## KP-B08｜第二组例8：由阶跃曲线估对象并求PI范围 { #kp-b08 }

**题面要素（摘要）**

由未知对象阶跃曲线估计K0与T，使用PI后要求稳态误差为0，并限制原系统相位裕量下降在0°—5.7°。

**来源定位**

《清华大学〈822控制工程基础〉重点题与答案》PDF p.39–40；与 `KP-A16S` 为重复/讲义变体。该资料为第三方整理，本项目只保留题型摘要、独立推导和核验意见，不复制整页题面或扫描答案。

**对应知识点**

`C7.3`, `C7.5`, `C7.6`；母题 `Q-C7-03`。

### 参考资料给出的路线

资料围绕“由阶跃曲线估对象并求PI范围”给出题面与演算/图解。数值结论仅在与定义、量纲和独立计算一致时采用；资料中的图形读数应回看原页。

### 我的重构解法

1. 由稳态误差指标确定低频增益或积分系数。
2. 由期望交叉频率确定比例增益，并把 PI 零点放在交叉频率以下。
3. 计算 PI 在交叉频率带来的相位滞后，保留足够相位裕度。
4. 重新求校正后交叉频率、裕度、误差和时域响应。

### 数值/结论检查点

由原阶跃曲线估计低频增益 \(K_0=7\) 与时间常数约0.2s；PI参数范围由相位裕度变化限制，资料给出 \(K_i\in[0,3.5]\) 的示例。

### 复核清单

- 只用误差指标求 Ki 不复核稳定
- 零点过靠近交叉频率
- 把 PI 当纯积分

!!! tip "我的思考"
    PI 的积分解决低频误差，但它会消耗相位。好的设计不是“加一个积分”，而是控制积分零点对中频的伤害。 重点题资料的价值在于暴露高频母题，但它不是官方评分标准；应以可复算步骤而不是“背答案截图”为准。
