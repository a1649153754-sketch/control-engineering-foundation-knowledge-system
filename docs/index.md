# 控制工程基础知识体系

> 基于《控制工程基础（第4版）》与配套《习题解（第4版）》建立的可持续学习项目：从物理对象出发，经数学模型、时域与频域分析、稳定与误差评价，再进入校正、根轨迹、非线性和计算机控制。

<div class="grid cards" markdown>

-   **11 章 / 77 个稳定节点**

    章节与小节编号沿用教材结构，扩展内容不打乱原节点。

-   **193 道习题逐题解析**

    配套习题解第 1—10 章已全部挂接到节点、母题、公式和易错边界。

-   **MathJax LaTeX 公式渲染**

    表格内公式与独立显示公式均可渲染，并支持移动端横向滚动。

-   **231 张规则卡 + 78 类母题**

    不只给公式，还记录触发条件、第一动作、复核方式和失效边界。

</div>
