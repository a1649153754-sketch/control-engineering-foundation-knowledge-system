# 控制工程基础知识体系

> 基于《控制工程基础（第4版）》与配套《习题解（第4版）》建立的可持续学习项目：从物理对象出发，经数学模型、时域与频域分析、稳定与误差评价，再进入校正、根轨迹、非线性和计算机控制。

<div class="grid cards" markdown>

-   **11 章 / 77 个稳定节点**

    章节与小节编号沿用教材结构，扩展内容不打乱原节点。

-   **385 个三级检查项**

    每个节点都要求“识别—调用—边界—验证—迁移”。

-   **231 张规则与公式卡**

    不只给公式，还记录触发条件、计算路线和失效边界。

-   **78 类母题 + 44 张边界卡**

    把习题解中的题型训练转成可检索的第一动作与错因系统。

</div>

## 三条学习主线

<div class="grid cards" markdown>

-   **[建模线](02-dynamic-models.md)**

    物理定律 → 微分方程 → 传递函数/方块图/信号流图 → 状态空间。

-   **[分析线](03-time-response.md)**

    时域 → 频域 → 稳定性 → 误差 → 根轨迹与非线性。

-   **[设计与实现线](07-design-compensation.md)**

    指标 → 校正/PID → 数字实现 → MATLAB/LabVIEW 验证。

</div>
