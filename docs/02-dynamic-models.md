## C2.1 微分方程表示的基本环节数学模型

**学习目标**：能从机械、电气和机电基本元件的物理定律建立线性常微分方程，并识别储能、耗能和传递元件。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给出质量—弹簧—阻尼、电阻—电感—电容或电机结构，要求建立输入输出微分方程。 |
| 主方法 | 先规定正方向和变量，再画受力/回路图；列平衡方程，统一到输入在右、输出及其导数在左的标准形式。 |
| 核心关系 | 平动：$M\ddot{x}+D\dot{x}+kx=f(t)$；转动：$J\ddot{\theta}+D\dot{\theta}+k\theta=T(t)$；电路：依据 KVL/KCL。 |
| 失效边界 | 符号、参考方向和初始条件必须一致；串并联机械元件不能简单照搬电路等效关系。 |
| 达标证据 | 能独立完成至少一种机械系统和一种电路系统的微分方程建模并检查量纲。 |

## C2.2 数学模型的线性化

**学习目标**：掌握工作点附近的小偏差线性化，理解线性模型的局部有效性。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 系统关系含非线性函数、乘积或参数曲线，题目要求在指定工作点附近建立线性增量模型。 |
| 主方法 | 选定工作点，定义增量变量，作一阶泰勒展开并删除二阶以上小量；最后把常值平衡项消去。 |
| 核心关系 | $\Delta y\approx \left.\dfrac{\partial f}{\partial x_1}\right\rvert_0\Delta x_1+\cdots+\left.\dfrac{\partial f}{\partial x_n}\right\rvert_0\Delta x_n$。 |
| 失效边界 | 线性化模型只在工作点邻域有效；工作点不满足静态平衡时，不能直接消去常值项。 |
| 达标证据 | 能写出线性化步骤、增益系数的物理含义和适用范围。 |
| 标签 | 线性化 · 工作点 · 泰勒展开 |

| 题目信号 | 题目出现微分方程求解、延迟/分段函数、卷积或有理函数反演。 |

## C2.4 传递函数以及典型环节的传递函数

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目给出微分方程、物理环节或极零点，要求写传递函数、标准化并识别环节。 |
| 主方法 | 零初始条件下取输出与输入拉氏变换之比；因式分解后提取增益，按比例、积分、微分、惯性、振荡、延迟等环节分类。 |

| 达标证据 | 能从三种表示互换：微分方程、极零点/时间常数形式、传递函数方块。 |

| --- | --- |
| 题目信号 | 出现多重反馈、交叉支路或要求某两个内部信号之间传递函数。 |

## C2.6 系统信号流图及梅逊公式

**学习目标**：掌握信号流图术语和梅逊增益公式，用路径与回路分析多变量因果关系。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 方块图难以化简，或题目直接给出信号流图并要求输入输出传递函数。 |
| 主方法 | 列出所有前向通路、单回路、互不接触回路组合，计算图行列式，再按梅逊公式求总增益。 |
| 核心关系 | $T=\dfrac{\sum_k P_k\Delta_k}{\Delta}$，$\Delta=1-\sum L_i+\sum L_iL_j-\cdots$。 |
| 失效边界 | 前向通路不能重复节点；“互不接触”指没有共同节点，不只是没有共同支路。 |
| 达标证据 | 能完整列出路径和回路，且能用方块图结果交叉验证。 |
| 标签 | 信号流图 · 梅逊公式 · 因果图 |
