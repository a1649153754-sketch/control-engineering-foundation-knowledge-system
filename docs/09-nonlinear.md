## C9.1 概述

**学习目标**：理解饱和、死区、间隙、继电等典型非线性及其导致的叠加原理失效、极限环和多平衡点。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 系统含分段元件或响应出现自振、跳变、依赖初值。 |
| 主方法 | 先画非线性静特性并分类；判断是否可局部线性化，若关注周期运动用描述函数，若关注全局轨迹用相平面/Lyapunov。 |
| 核心关系 | 非线性系统一般不满足叠加原理，传递函数不能完整描述其全局行为。 |
| 失效边界 | 局部线性稳定不等于全局稳定；不同初值可能进入不同吸引域。 |
| 达标证据 | 能识别四类典型非线性并选择合适分析方法。 |
| 标签 | 非线性概述 · 典型非线性 · 方法选择 |

## C9.2 描述函数法

**学习目标**：掌握描述函数的概念，用基波近似分析非线性闭环的极限环条件。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 非线性元件输入近似正弦，要求自振幅值、频率或稳定性。 |
| 主方法 | 求非线性输出基波，得到 $N(A)$；与线性部分频率响应满足谐波平衡条件，求交点。 |
| 核心关系 | $1+N(A)G(j\omega)=0$，即 $G(j\omega)=-1/N(A)$。 |
| 失效边界 | 描述函数忽略高次谐波，适用于线性部分对高频有足够衰减且周期运动近似正弦的情形。 |
| 达标证据 | 能为继电、饱和或死区写出分析流程并判断交点物理意义。 |
| 标签 | 描述函数 · 谐波平衡 · 极限环 |

## C9.3 相轨迹法

**学习目标**：掌握二阶自治系统相平面、奇点分类、等倾线和相轨迹绘制。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给二阶非线性微分方程，要求相轨迹、奇点性质或运动区域。 |
| 主方法 | 令 $x_1=x,\ x_2=\dot x$ 得一阶系统；消去时间写 $dx_2/dx_1$，求奇点并在各区域判断方向。 |
| 核心关系 | $\dfrac{dx_2}{dx_1}=\dfrac{\dot x_2}{\dot x_1}$；相轨迹方向由时间导数符号确定。 |
| 失效边界 | 相轨迹不能相交（除奇点等特殊情形），因为同一点状态的未来演化应唯一。 |
| 达标证据 | 能绘制一个分段非线性二阶系统的相平面草图并标方向。 |
| 标签 | 相轨迹 · 相平面 · 奇点 |

## C9.4 李雅普诺夫稳定性方法

**学习目标**：理解 Lyapunov 直接法，通过构造正定函数和导数符号判断平衡点稳定性。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 不易显式求解非线性微分方程，要求证明稳定、渐近稳定或估计吸引域。 |
| 主方法 | 平移平衡点到原点；选候选能量函数 $V(x)$，检查正定性；沿系统轨迹求 $\dot V$ 并判断负定/半负定。 |
| 核心关系 | $V(x)>0,\ \dot V(x)<0$（原点外）常可推出渐近稳定；具体结论需满足定理条件。 |
| 失效边界 | 找到一个候选函数失败不代表系统不稳定；$\dot V\le0$ 仅半负定时需进一步分析不变集。 |
| 达标证据 | 能为简单二阶系统构造二次型 Lyapunov 函数并说明结论范围。 |
| 标签 | Lyapunov · 直接法 · 稳定证明 |

| --- | --- |
| 题目信号 | 解析解困难，需要观察极限环、吸引域或不同初值。 |
| 主方法 | 建立状态方程，用 ODE 求解器积分；绘制时间响应和相平面；改变初值/参数验证局部与全局现象。 |
