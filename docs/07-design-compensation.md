## C7.1 系统的性能指标

**学习目标**：把时域、频域、稳态和稳定裕度指标转化为可设计约束，理解指标间的相互制约。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 设计题同时给出超调、调整时间、稳态误差、带宽或裕度要求。 |
| 主方法 | 把时域指标换算为主导二阶参数区间，把稳态精度换算为低频增益/型别，把鲁棒性换算为裕度，再检查可兼容性。 |
| 核心关系 | 典型映射：$M_p\leftrightarrow\zeta$，$t_s\leftrightarrow\zeta\omega_n$，$e_{ss}\leftrightarrow$ 低频增益与系统型别。 |
| 失效边界 | 不同近似公式有适用条件；设计指标不是彼此独立，追求更快常会牺牲超调、噪声和控制能量。 |
| 达标证据 | 能把一组文字指标转换成极点区域、低频增益和交叉频率目标。 |
| 标签 | 性能指标 · 设计约束 · 指标映射 |

## C7.3 串联校正

**学习目标**：掌握超前、滞后、滞后—超前等串联校正的频率作用和参数设计。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 开环裕度不足、响应慢或稳态精度不足，要求设计串联网络。 |
| 主方法 | 先选目标交叉频率；超前提供正相位并提高中频增益，滞后提高低频相对增益并尽量少影响交叉频段；迭代校核。 |
| 核心关系 | 超前环节常写为 $G_c(s)=K_c\dfrac{Ts+1}{\alpha Ts+1}$，$0<\alpha<1$；最大超前角由 $\alpha$ 决定。 |
| 失效边界 | 滞后不是“让系统更慢就一定更稳”；若转折频率选错，会显著侵蚀相位裕度。 |
| 达标证据 | 能完成一次超前或滞后校正手算，画校正前后 Bode 草图并复核指标。 |
| 标签 | 串联校正 · 超前 · 滞后 |

## C7.5 用频率法对控制系统进行综合与校正

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给定对象和频域/时域指标，要求设计校正器并验证。 |
| 主方法 | 步骤：指标换算 → 画对象 Bode → 选 $\omega_c$ → 计算所需相位/增益 → 布置校正零极点 → 调整增益 → 全指标复核。 |
| 核心关系 | 设计中常留额外相位余量补偿近似误差，并检查校正后实际交叉频率。 |
| 失效边界 | 只在一个频点满足相位条件不够；必须检查低频精度、高频衰减、全局稳定和控制器可实现性。 |

## C7.7 确定 PID 参数的其他方法

**学习目标**：理解 PID 三项作用及临界比例法、响应曲线法等参数整定思想。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目要求选择 P/PI/PD/PID 或根据实验特征整定参数。 |
| 主方法 | 先诊断误差、阻尼和噪声需求；P 调增益，I 提低频型别，D 提供预测/阻尼但放大高频噪声；再按指定经验法给初值并复核。 |
| 核心关系 | $G_c(s)=K_p+K_i/s+K_ds$，实际微分常需加滤波。 |
| 失效边界 | 经验整定给的是起始参数，不是对所有对象的保证；纯微分不可物理实现，积分需考虑饱和。 |
| 达标证据 | 能比较 P、PI、PD、PID 对稳态和瞬态的主要影响，并完成一次参数整定。 |

## C7.9 小结

**学习目标**：形成“指标—结构—参数—验证”的校正总框架，并能解释性能折中。

| 字段 | 内容 |
| --- | --- |
