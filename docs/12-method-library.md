# 跨章节方法库

> 题目表面在不同章节，底层经常重复同一套动作：定义变量、选择表示、检查条件、做极限与交叉验证。

## M1 · 建模五步法

1. **定对象**：画系统边界，明确输入、输出、扰动。
2. **定变量**：规定正方向、参考点、单位和初始条件。
3. **列定律**：机械用力/力矩平衡，电路用 KCL/KVL，机电用耦合关系。
4. **选表示**：微分方程适合物理推导；传递函数适合单输入输出经典分析；状态空间适合内部状态和多变量。
5. **做校验**：量纲、静态极限、高频极限、能量与符号。

## M2 · 标准化优先

看到多项式或传递函数，先做：

- 最高次项系数归一；
- 提取总增益；
- 分解原点极点、实极点、复极点和零点；
- 写成时间常数/自然频率—阻尼比形式；
- 标注单位与采样时间。

很多“公式不会用”，本质是还没有把对象化为标准形。

## M3 · 三种表示互证

| 表示 | 最擅长回答 | 交叉验证 |
| --- | --- | --- |
| 微分方程 | 物理项从哪里来 | 与初始条件、量纲核对 |
| 传递函数/极零点 | 输入输出动态和经典分析 | 与微分方程阶数、直流增益核对 |
| 状态空间 | 内部状态、多变量、实现 | 与传递函数、特征值核对 |

## M4 · 极点—模态—性能链

1. 特征根/极点决定自然模态；
2. 实部决定衰减或发散；
3. 虚部决定振荡频率；
4. 极点与零点共同决定留数和实际响应权重；
5. 主导极点近似必须检查零点与非主导模态。

## M5 · 低频—中频—高频分工

- **低频**：稳态精度、系统型别、慢扰动抑制；
- **中频/交叉频段**：带宽、相位裕度、主要瞬态性能；
- **高频**：噪声、未建模动态、控制器可实现性。

频率法设计不是“把曲线抬高”，而是在三个频段有目的地整形。

## M6 · 终值定理检查表

使用终值定理前：

1. 写清要取终值的信号；
2. 构造 `sF(s)`；
3. 检查其除原点允许因素外的极点；
4. 确认闭环稳定或相应条件；
5. 若不满足，改用时域解或极点分析。

## M7 · 参数临界值三种求法

| 任务 | 首选 |
| --- | --- |
| 多项式参数稳定区间 | Routh/Jury |
| 频率临界增益或延迟 | Nyquist/Bode |
| 闭环极点随参数移动 | 根轨迹 |

三种方法应在重叠问题上给出一致临界结果。

## M8 · “先结构，后数值”

复杂题先写结构：

- 误差传递函数；
- 闭环特征方程；
- 频率条件；
- 根轨迹相角条件；
- 校正器结构。

结构正确后再代参数。反过来一上来算数，最容易把反馈符号和作用点算丢。

## M9 · 近似的四个问题

每次近似都回答：

1. 忽略了什么？
2. 为什么在当前频段/时间尺度小？
3. 近似误差怎样估计？
4. 改变参数后近似是否仍成立？

适用于线性化、主导极点、渐近 Bode、Pade 延迟、描述函数和连续控制器离散化。

## M10 · 软件结果四重校验

1. **结构**：模型连接和反馈符号；
2. **极限**：初值、终值、低频、高频；
3. **极点**：稳定性与响应趋势；
4. **数值**：步长、频率网格、采样时间、单位。

## M11 · 设计题标准答卷

```text
需求与约束
→ 对象模型与基线指标
→ 主要矛盾诊断
→ 控制结构选择
→ 参数计算
→ 稳定性、误差、时域、频域、控制量验证
→ 实现与鲁棒性说明
```

## M12 · 证明/解释题模板

- **定义层**：先说明研究的量；
- **条件层**：列出定理或公式成立条件；
- **关系层**：用方程或图形建立因果链；
- **结论层**：只推出条件允许的结论；
- **边界层**：给出一个失效情形或反例。

## M13 · 手算与软件分工

手算负责：

- 结构、条件、趋势、临界值和解释；
- 低阶精确式与高阶近似依据。

软件负责：

- 高阶根、参数扫描、精确曲线、多方案比较；
- 但不得替代条件检查和物理解释。

## M14 · 一题多解的价值

同一问题可用时域、频域、Routh、Nyquist、根轨迹或状态空间处理。多解不是炫技，价值在于：

- 发现符号或数值错误；
- 看见不同指标之间的联系；
- 选择考试/工程中最省力的路线；
- 明确每种方法的适用边界。
