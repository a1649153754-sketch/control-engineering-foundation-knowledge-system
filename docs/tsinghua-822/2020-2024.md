## TH-2020-01｜2020 年第 01 题：四组极点图的5%调整时间 { #th-2020-01 }

**题源摘要（非逐字转录）**

与2013/2015/2018同族。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.69。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C3.3`, `C3.4`, `C3.5`；母题 `Q-C3-06`。

### 我的独立推导路线（非官方答案）

1. 把每组极点按实部、阻尼比、虚部和是否在右半平面分类。
2. 由最靠近虚轴且留数不小的极点估计衰减速度；由复极点角度判断振荡。
3. 检查是否存在不稳定极点、近原点实极点或高频快极点。
4. 将稳态增益、超调、振荡频率和调整时间逐项与曲线匹配。

### 关键公式与判据

- $$\zeta=-\frac{\sigma}{\sqrt{\sigma^2+\omega_d^2}}$$
- $$t_s(5\%)\approx\frac{3}{|\sigma_d|}$$

## TH-2020-02｜2020 年第 02 题：高阶对象无/有反馈的稳态与95%时间 { #th-2020-02 }

**题源摘要（非逐字转录）**

G(s)=100000/[(s^2+2×0.5×10s+100)(s+50)]，单位阶跃。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.69。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C3.2`, `C3.3`, `C3.4`, `C3.5`；母题 `Q-C3-04`。

### 我的独立推导路线（非官方答案）

1. 先求闭环传递函数并检查闭环稳定。
2. 归一化分母，识别一阶、标准二阶或高阶主导极点结构。
3. 用终值定理求稳态值；欠阻尼二阶再计算超调、峰值、调整时间。
4. 有零点/附加极点时，用部分分式或留数修正标准二阶近似。

### 关键公式与判据

- $$M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}$$
- $$t_s(5\%)\approx\frac{3}{\zeta\omega_n}$$
- $$t_p=\frac{\pi}{\omega_n\sqrt{1-\zeta^2}}$$

## TH-2020-03｜2020 年第 03 题：超前校正器参数求解 { #th-2020-03 }

**题源摘要（非逐字转录）**

Gp=100/[s(s+5)]，Gc=K(T1s+1)/(T2s+1)，要求ωc=20rad/s、相位裕度45°，求K,T1,T2。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.70。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C7.2`, `C7.5`；母题 `Q-C7-02`。

### 我的独立推导路线（非官方答案）

1. 由原系统 Bode 图求当前交叉频率和相位裕度。
2. 按目标裕度加安全余量确定所需最大超前相角。
3. 由 α 与中心频率配置零、极点，再调增益使新交叉频率落在超前峰附近。
4. 对校正后系统重新计算误差、裕度、带宽和高频增益。

### 关键公式与判据

- $$G_c(s)=K\frac{Ts+1}{\alpha Ts+1},\quad0<\alpha<1$$
- $$\phi_{max}=\sin^{-1}\frac{1-\alpha}{1+\alpha}$$

### 结论/核验状态

原卷仅提供题面，未附官方答案。本知识库给出可复核的完整解题路线；涉及扫描图尺寸或小字参数时，应回看原卷页。

### 易错点

- 把旧交叉频率当新交叉频率
- 缺相不加安全余量
- 高频增益与噪声风险未评估

!!! tip "我的思考：为什么这题值得收进体系"
    超前校正本质是把交叉频率推到更高处并补相。它换来速度，也同时提高了对高频模型误差的敏感度。

- $$T=\frac{G}{1\pm GH}$$
- $$T=\frac{\sum_k P_k\Delta_k}{\Delta}$$

### 关键公式与判据

- $$G_{eq}=\frac{G}{1+GH}$$
- $$E(s)=S(s)R(s)-S(s)G_d(s)N(s)$$
