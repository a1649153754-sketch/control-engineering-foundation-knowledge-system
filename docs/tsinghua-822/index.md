## 使用规则

1. 先读题源摘要并回原卷确认图形与参数。
2. 遮住“结论/核验状态”，按“独立推导路线”完成。
3. 把错误挂到知识节点、母题和错因标签。
4. 对扫描不清或无官方答案的题，保留“待复核”，不把猜测固化。
