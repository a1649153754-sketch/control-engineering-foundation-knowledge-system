## TH-1995-01｜1995 年第 01 题：杠杆—质量—弹簧—阻尼系统传递函数 { #th-1995-01 }

**题源摘要（非逐字转录）**

以端部外力 f(t) 为输入、质量块位移 x_o(t) 为输出；参数含杠杆臂 a、b、c，质量 m，阻尼 μ1、μ2 与弹簧 k1、k2、k3。需把不同作用点的位移按刚性杠杆几何关系折算。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.1。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C2.1`, `C2.7`, `C2.8`；母题 `Q-C2-01`。

### 我的独立推导路线（非官方答案）

1. 统一正方向和广义坐标，先画每个刚体/质量块的受力图或力矩图。
2. 用几何约束、杠杆比、齿轮比或丝杠导程把各点位移与速度折算到同一坐标。
3. 分别列牛顿第二定律或转动方程；弹簧、阻尼力必须写成相对位移与相对速度。
4. 在零初始条件下作拉氏变换，联立消元得到指定输入到输出的传递函数。
5. 用量纲、静态极限、高频阶次和极端参数退化检查结果。

### 关键公式与判据

- $$F(s)=Ms^2X(s)+DsX(s)+KX(s)$$
- $$T(s)=Js^2\Theta(s)+Ds\Theta(s)+K\Theta(s)$$

## TH-1995-02｜1995 年第 02 题：两类有理函数的 Z 反变换 { #th-1995-02 }

**题源摘要（非逐字转录）**

分别对 X(z)=z/[(z-1)^2(z-2)] 与含 e^{-3T}、e^{-aT} 极点的三因子有理式求序列。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.1。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C10.2`, `C10.3`；母题 `Q-C10-02`。

### 我的独立推导路线（非官方答案）

1. 明确是序列的单边 Z 变换还是双边 Z 变换，并写采样周期。
2. 先做因式分解或部分分式，再匹配标准序列。
3. 若由连续信号采样，先写 x(kT)，不要把 s 直接换成 z。
4. 用初值/终值定理时先检查极点条件。

### 关键公式与判据

- $$X(z)=\sum_{k=0}^{\infty}x(kT)z^{-k}$$
- $$\mathcal Z\{a^k\}=\frac{z}{z-a}$$

### 结论/核验状态

第一式应先作部分分式并注意 z/(z-a) 与 a^k 的对应；第二式保留指数参数后同样按互异极点展开。

### 易错点

- 忽略收敛域
- z^{-1} 与一步延迟对应关系错
- 重极点反变换系数漏导数

!!! tip "我的思考：为什么这题值得收进体系"
    离散题的本质是“序列的极点半径和角度”。先看极点几何，再算代数，能提前判断衰减、振荡与稳定。
