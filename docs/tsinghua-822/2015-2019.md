## TH-2015-01｜2015 年第 01 题：杠杆—质量—多弹簧阻尼系统 { #th-2015-01 }

**题源摘要（非逐字转录）**

与1995/1996同族，参数a,b,c,m,μ1,μ2,k1,k2,k3，求f到x_o。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.54。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C2.1`, `C2.7`, `C2.8`；母题 `Q-C2-01`。

### 我的独立推导路线（非官方答案）

1. 统一正方向和广义坐标，先画每个刚体/质量块的受力图或力矩图。
2. 用几何约束、杠杆比、齿轮比或丝杠导程把各点位移与速度折算到同一坐标。
3. 分别列牛顿第二定律或转动方程；弹簧、阻尼力必须写成相对位移与相对速度。
4. 在零初始条件下作拉氏变换，联立消元得到指定输入到输出的传递函数。
5. 用量纲、静态极限、高频阶次和极端参数退化检查结果。

### 关键公式与判据

- $$F(s)=Ms^2X(s)+DsX(s)+KX(s)$$
- $$T(s)=Js^2\Theta(s)+Ds\Theta(s)+K\Theta(s)$$

### 结论/核验状态

原卷仅提供题面，未附官方答案。本知识库给出可复核的完整解题路线；涉及扫描图尺寸或小字参数时，应回看原卷页。

### 易错点

- 把绝对位移误写成相对位移
- 漏掉作用反作用力
- 杠杆/齿轮折算方向或平方关系错误

!!! tip "我的思考：为什么这题值得收进体系"
    这类题真正考的是“选坐标—写兼容条件—守住能量/量纲”。传递函数只是最后的消元结果。

## TH-2015-02｜2015 年第 02 题：四组极点图的5%调整时间 { #th-2015-02 }

**题源摘要（非逐字转录）**

### 关键公式与判据

- $$\zeta=-\frac{\sigma}{\sqrt{\sigma^2+\omega_d^2}}$$

对象 K/[(Ts+1)(s^2+2ξω_ns+ω_n^2)]，PD=Kp+Kds，所有参数正，求闭环稳定充分条件。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.55。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C7.3`, `C7.5`, `C7.6`, `C8.5`；母题 `Q-C7-02`。

### 我的独立推导路线（非官方答案）

1. 把 PD 写成 Kp+Kds，代入闭环特征方程。
2. 按目标极点/标准二阶系数比较或按频域缺相确定零点与增益。
3. 写出参数为正、闭环特征多项式稳定的条件。
4. 考虑高频噪声，工程实现时加入微分滤波。

### 关键公式与判据

- $$G_c(s)=K_p+K_ds=K_d(s+K_p/K_d)$$

### 结论/核验状态

原卷仅提供题面，未附官方答案。本知识库给出可复核的完整解题路线；涉及扫描图尺寸或小字参数时，应回看原卷页。

### 易错点

- 理想微分直接实现
- 系数匹配漏高阶项
- 只保证目标二阶因子却忽略剩余极点

!!! tip "我的思考：为什么这题值得收进体系"
    可把特征多项式展开后用三阶 Routh 条件，得到 Kp、Kd 与对象参数的耦合不等式。

## TH-2016-03｜2016 年第 03 题：高阶开环/闭环阶跃稳态和95%时间 { #th-2016-03 }

**题源摘要（非逐字转录）**

G(s)=100000/[(s^2+10s+100)(s+50)]，无/有单位反馈。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.57。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C3.2`, `C3.3`, `C3.4`, `C3.5`；母题 `Q-C3-04`。

### 我的独立推导路线（非官方答案）

1. 先求闭环传递函数并检查闭环稳定。
2. 归一化分母，识别一阶、标准二阶或高阶主导极点结构。
3. 用终值定理求稳态值；欠阻尼二阶再计算超调、峰值、调整时间。
4. 有零点/附加极点时，用部分分式或留数修正标准二阶近似。

### 关键公式与判据

- $$M_p=e^{-\pi\zeta/\sqrt{1-\zeta^2}}$$
- $$t_s(5\%)\approx\frac{3}{\zeta\omega_n}$$
- $$t_p=\frac{\pi}{\omega_n\sqrt{1-\zeta^2}}$$

### 结论/核验状态

### 易错点

- 未归一化直接读参数
- 2%/5%误差带混用
- 闭环零点影响被忽略

!!! tip "我的思考：为什么这题值得收进体系"
    极点给出模态，零点和留数决定模态权重。相同主导极点并不保证相同超调，这是清华题反复考的暗线。

### 关键公式与判据

- $$\text{Routh first column sign changes}=N_{RHP}$$

## TH-2016-05｜2016 年第 05 题：由最小相位 Bode 图反求传递函数 { #th-2016-05 }

**题源摘要（非逐字转录）**

幅频从低频+40dB/dec上升，经0.01、0.04转折后变为0斜率，ζ=1，求传递函数。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.58。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C4.3`, `C4.4`；母题 `Q-C4-04`。

### 我的独立推导路线（非官方答案）

1. 从低频斜率确定系统型别，从低频幅值确定增益。
2. 每个斜率变化点对应一阶零/极点或二阶环节；记录变化量和转折频率。
3. 由相位趋势区分最小相位零点、非最小相位零点和延迟；只有幅值时声明不唯一性。
4. 重构传递函数后回画渐近线，核对各段斜率和交叉频率。

### 关键公式与判据

- $$20\log_{10}|G(j\omega)|$$
- $$\Delta slope=\pm20\ \mathrm{dB/dec}\text{ per first-order factor}$$

### 结论/核验状态

### 易错点

- 把 Hz 当 rad/s
- 仅凭幅值唯一确定零点半平面
