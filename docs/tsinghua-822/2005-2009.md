**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.26。原卷图形、完整选项与元件标注请回源文件核对。

## TH-2005-02｜2005 年第 02 题：含零点系统的最大允许增益 { #th-2005-02 }

**题源摘要（非逐字转录）**

单位反馈 G(s)=K(Ts+1)/[s(0.01s+1)(s+1)]，要求无穷大增益裕度时 K 的最大可能值。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.26。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 我的独立推导路线（非官方答案）

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 关键公式与判据

- $$1+G(s)H(s)=0$$
- $$K_g=\frac1{|G(j\omega_g)H(j\omega_g)|}$$
- $$\gamma=180^\circ+\angle G(j\omega_c)H(j\omega_c)$$

### 结论/核验状态

### 易错点

- 不先数 P
- 环绕方向约定前后不一致
- 有多个交叉频率仍套单交叉结论

!!! tip "我的思考：为什么这题值得收进体系"
    “无穷大增益裕度”意味着 Nyquist 不在有限增益下触及负实轴临界点，需要从相位交叉结构判断。

## TH-2005-03｜2005 年第 03 题：模拟控制器双线性离散化与频率特性比较 { #th-2005-03 }

**题源摘要（非逐字转录）**

模拟PID Gc(s)=2(s+5)(s+40)/s，T=0.02；双线性变换求Dc(z)、差分方程，并比较数字/模拟截止频率和相位裕度。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.27。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C10.1`, `C10.2`, `C10.4`；母题 `Q-C10-06`。

### 我的独立推导路线（非官方答案）

1. 明确采样周期、离散化方法和连续控制器/对象的位置。
2. 双线性变换用 s=2/T·(z-1)/(z+1)，ZOH 等效则先求保持器与对象的脉冲传递函数。
3. 将 D(z) 化成 z^{-1} 多项式，交叉相乘写出可实现差分方程。
4. 比较离散极点、频率畸变和采样周期变化对稳定/动态的影响。

### 关键公式与判据

- $$s=\frac{2}{T}\frac{z-1}{z+1}$$
- $$G_h(z)=(1-z^{-1})\mathcal Z\left\{\mathcal L^{-1}\left[\frac{G(s)}s\right]_{t=kT}\right\}$$

## TH-2005-04｜2005 年第 04 题：同时满足 K、相位裕度与增益裕度的校正 { #th-2005-04 }

**题源摘要（非逐字转录）**

开环 K/[s(0.5s+1)]，要求K=20、相位裕度≥50°、增益裕度≥10dB，设计校正装置。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.27。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C7.2`, `C7.5`；母题 `Q-C7-02`。

### 我的独立推导路线（非官方答案）

1. 由原系统 Bode 图求当前交叉频率和相位裕度。
2. 按目标裕度加安全余量确定所需最大超前相角。
3. 由 α 与中心频率配置零、极点，再调增益使新交叉频率落在超前峰附近。
4. 对校正后系统重新计算误差、裕度、带宽和高频增益。

### 关键公式与判据

- $$G_c(s)=K\frac{Ts+1}{\alpha Ts+1},\quad0<\alpha<1$$
- $$\phi_{max}=\sin^{-1}\frac{1-\alpha}{1+\alpha}$$

### 结论/核验状态

原卷仅提供题面，未附官方答案。本知识库给出可复核的完整解题路线；涉及扫描图尺寸或小字参数时，应回看原卷页。

### 易错点

- 把旧交叉频率当新交叉频率
- 缺相不加安全余量
- 高频增益与噪声风险未评估

!!! tip "我的思考：为什么这题值得收进体系"
    超前校正本质是把交叉频率推到更高处并补相。它换来速度，也同时提高了对高频模型误差的敏感度。

## TH-2009-01｜2009 年第 01 题：由正频 Nyquist 补全全图并反推开环性质 { #th-2009-01 }

**题源摘要（非逐字转录）**

已知最小相位系统正频部分Nyquist和反馈系数H=2，画完整Nyquist并估算开环增益/闭环性质。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.36。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 我的独立推导路线（非官方答案）

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 关键公式与判据

- $$1+G(s)H(s)=0$$
- $$K_g=\frac1{|G(j\omega_g)H(j\omega_g)|}$$
- $$\gamma=180^\circ+\angle G(j\omega_c)H(j\omega_c)$$

## TH-2009-03｜2009 年第 03 题：按时域指标与稳态误差设计超前校正 { #th-2009-03 }

**题源摘要（非逐字转录）**

对象4/[(0.2s+1)(0.05s+1)]；先求阶跃与扰动误差，再要求峰值时间、超调量和稳态误差设计超前装置。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.37。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C7.2`, `C7.5`；母题 `Q-C7-02`。

### 我的独立推导路线（非官方答案）

1. 由原系统 Bode 图求当前交叉频率和相位裕度。
2. 按目标裕度加安全余量确定所需最大超前相角。
3. 由 α 与中心频率配置零、极点，再调增益使新交叉频率落在超前峰附近。
4. 对校正后系统重新计算误差、裕度、带宽和高频增益。

### 关键公式与判据

- $$G_c(s)=K\frac{Ts+1}{\alpha Ts+1},\quad0<\alpha<1$$
- $$\phi_{max}=\sin^{-1}\frac{1-\alpha}{1+\alpha}$$

- 把旧交叉频率当新交叉频率

- 高频增益与噪声风险未评估

!!! tip "我的思考：为什么这题值得收进体系"
    超前校正本质是把交叉频率推到更高处并补相。它换来速度，也同时提高了对高频模型误差的敏感度。
