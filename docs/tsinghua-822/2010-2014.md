## TH-2010-01｜2010 年第 01 题：Nyquist 判稳并求增益裕度 { #th-2010-01 }

**题源摘要（非逐字转录）**

G(s)=10/(s^3+8s^2+25s)，单位负反馈，判断稳定并求增益裕度。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.39。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C4.2`, `C5.4`, `C5.7`；母题 `Q-C5-05`。

### 我的独立推导路线（非官方答案）

1. 先数开环右半平面极点 P，并说明 Nyquist 路径对虚轴极点的绕行。
2. 求低频、高频极限、与实轴/虚轴交点及频率方向，补全负频共轭部分。
3. 按统一符号约定统计对 -1 点的环绕数 N，利用 Z=P+N（或所采用等价约定）判断闭环右半平面根数。
4. 增益裕量由相位交叉处幅值求，相位裕量由增益交叉处相位求。

### 关键公式与判据

- $$1+G(s)H(s)=0$$
- $$K_g=\frac1{|G(j\omega_g)H(j\omega_g)|}$$
- $$\gamma=180^\circ+\angle G(j\omega_c)H(j\omega_c)$$

### 结论/核验状态

### 易错点

- 不先数 P
- 环绕方向约定前后不一致
- 有多个交叉频率仍套单交叉结论

!!! tip "我的思考：为什么这题值得收进体系"
    Nyquist 不是画漂亮曲线，而是把“开环右半平面极点数”转成“闭环零点数”。曲线细节服务于拓扑计数。

2. 由目标闭环模型或系数匹配确定参数；若用频域法，分别分配低频积分和中频相位提升。

- $$G_c(s)=K_p+\frac{K_i}{s}+K_ds=\frac{K_ds^2+K_ps+K_i}{s}$$

**题源摘要（非逐字转录）**

给最小相位开环渐近图，不要求先写开环；判断单位反馈稳定、估算ωc、阶跃误差，并提出提高快速性且降低误差的简单措施。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.40。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C4.3`, `C4.4`；母题 `Q-C4-04`。

### 我的独立推导路线（非官方答案）

1. 从低频斜率确定系统型别，从低频幅值确定增益。
2. 每个斜率变化点对应一阶零/极点或二阶环节；记录变化量和转折频率。
3. 由相位趋势区分最小相位零点、非最小相位零点和延迟；只有幅值时声明不唯一性。
4. 重构传递函数后回画渐近线，核对各段斜率和交叉频率。

### 关键公式与判据

- $$20\log_{10}|G(j\omega)|$$
- $$\Delta slope=\pm20\ \mathrm{dB/dec}\text{ per first-order factor}$$

## TH-2012-03｜2012 年第 03 题：模拟 PID 数字化与频域一致性 { #th-2012-03 }

**题源摘要（非逐字转录）**

Gc(s)=2(s+5)(s+40)/s，T=0.02，双线性变换求Dc(z)、差分方程，并讨论采样后截止频率/相位裕度差异及参数调整。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.44。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C10.1`, `C10.2`, `C10.4`；母题 `Q-C10-06`。

### 我的独立推导路线（非官方答案）

1. 明确采样周期、离散化方法和连续控制器/对象的位置。
