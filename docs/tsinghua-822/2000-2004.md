## TH-2000-01｜2000 年第 01 题：二自由度汽车悬架模型的两种输入通道 { #th-2000-01 }

**题源摘要（非逐字转录）**

车轮质量 M1、车体质量 M2，轮胎弹性、悬架弹簧和阻尼；分别求车体垂直力与路面位移到车体位移的传递函数。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.11。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C2.1`, `C2.7`, `C2.8`；母题 `Q-C2-01`。

### 我的独立推导路线（非官方答案）

1. 统一正方向和广义坐标，先画每个刚体/质量块的受力图或力矩图。
2. 用几何约束、杠杆比、齿轮比或丝杠导程把各点位移与速度折算到同一坐标。
3. 分别列牛顿第二定律或转动方程；弹簧、阻尼力必须写成相对位移与相对速度。
4. 在零初始条件下作拉氏变换，联立消元得到指定输入到输出的传递函数。
5. 用量纲、静态极限、高频阶次和极端参数退化检查结果。

### 关键公式与判据

- $$F(s)=Ms^2X(s)+DsX(s)+KX(s)$$
- $$T(s)=Js^2\Theta(s)+Ds\Theta(s)+K\Theta(s)$$

### 结论/核验状态

原卷仅提供题面，未附官方答案。本知识库给出可复核的完整解题路线；涉及扫描图尺寸或小字参数时，应回看原卷页。

### 易错点

- 把绝对位移误写成相对位移
- 漏掉作用反作用力
- 杠杆/齿轮折算方向或平方关系错误

!!! tip "我的思考：为什么这题值得收进体系"
    这类题真正考的是“选坐标—写兼容条件—守住能量/量纲”。传递函数只是最后的消元结果。

## TH-2000-02｜2000 年第 02 题：RC 梯形网络传递函数与 Bode 图 { #th-2000-02 }

**题源摘要（非逐字转录）**

与1998大题同族：输入电流，三电容和两电阻网络，求 Uo/Ii 及 Bode。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.11。原卷图形、完整选项与元件标注请回源文件核对。

`C2.1`, `C2.4`, `C2.8`；母题 `Q-C2-02`。

1. 先判理想运放、虚短/虚断是否适用；普通网络则选节点电压或回路电流。

- $$Z_C=\frac1{sC}$$
- $$Z_L=sL$$

## TH-2000-03｜2000 年第 03 题：三幅最小相位 Bode 图反求传递函数与裕度 { #th-2000-03 }

**题源摘要（非逐字转录）**

三幅渐近幅频图，要求反求开环、计算相位/幅值裕度并判断稳定。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.12。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C4.3`, `C4.4`；母题 `Q-C4-04`。

### 我的独立推导路线（非官方答案）

1. 从低频斜率确定系统型别，从低频幅值确定增益。
2. 每个斜率变化点对应一阶零/极点或二阶环节；记录变化量和转折频率。
3. 由相位趋势区分最小相位零点、非最小相位零点和延迟；只有幅值时声明不唯一性。
4. 重构传递函数后回画渐近线，核对各段斜率和交叉频率。

### 关键公式与判据

- $$20\log_{10}|G(j\omega)|$$
- $$\Delta slope=\pm20\ \mathrm{dB/dec}\text{ per first-order factor}$$

## TH-2000-04｜2000 年第 04 题：跟踪斜坡输入的稳态误差与控制器条件 { #th-2000-04 }

**题源摘要（非逐字转录）**

单位反馈，对象100/[s(s+5)]；输入 x_i(t)=(2+t)u(t)。比较 Gc=1 与 Gc=10(s+1)/[s^2(s+200)]，并求零稳态误差的 K 条件。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.12。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C6.1`, `C6.2`, `C6.3`, `C6.4`；母题 `Q-C6-04`。

### 我的独立推导路线（非官方答案）

1. 先定义物理误差，分别对参考输入和扰动建立传递通道。
2. 令其他输入为零，写 E(s)/R(s) 或 E(s)/N(s)。
3. 检查闭环稳定后用终值定理；对阶跃、斜坡、加速度输入匹配低频阶次。
4. 多输入同时作用时线性叠加，并对不确定幅值做符号/最坏组合。

### 关键公式与判据

- $$e_{ss}=\lim_{s\to0}sE(s)$$
- $$K_p=\lim_{s\to0}L(s),\quad K_v=\lim_{s\to0}sL(s),\quad K_a=\lim_{s\to0}s^2L(s)$$

### 易错点

- 未检查稳定就用终值定理

    稳态误差题最关键的问题不是“系统几型”，而是“输入从哪里进、误差在哪里量”。不同通道看到的低频环路并不相同。

## TH-2000-05｜2000 年第 05 题：电压—转角伺服系统全指标分析与滞后校正 { #th-2000-05 }

**题源摘要（非逐字转录）**

给电机与放大器参数、反馈系数、负载惯量和目标 T=2s、τ=0.2s。要求传递函数、开环、截止频率、相位裕度、误差系数及滞后网络。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.13。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C7.3`, `C7.5`；母题 `Q-C7-03`。

### 我的独立推导路线（非官方答案）

1. 由稳态误差指标求低频增益需提高的倍数 β。
2. 选择尽量保持原交叉频率的滞后零、极点，通常放在交叉频率低一数量级。
3. 调总增益并重新计算交叉频率与相位裕度。
4. 检查慢极点是否显著增加调整时间。

### 关键公式与判据

- $$G_c(s)=K\frac{Ts+1}{\beta Ts+1},\quad\beta>1$$

## TH-2001-01｜2001 年第 01 题：三角周期波的拉氏变换 { #th-2001-01 }

**题源摘要（非逐字转录）**

周期三角波幅值±1、周期4（图示），写时域表达式并求拉氏变换。

**来源定位**

《1995—2024 清华大学 822 控制工程基础真题》PDF p.14。原卷图形、完整选项与元件标注请回源文件核对。

**对应知识点**

`C2.3`；母题 `Q-C2-05`。

### 我的独立推导路线（非官方答案）

1. 先把波形写成单位阶跃、延迟和基本函数的组合。
2. 使用线性、延迟、周期函数或微分积分性质得到变换。
3. 反变换时先因式分解并作部分分式；含重复极点时用留数/导数公式。
4. 用初值、终值和时域连续性核验。

### 关键公式与判据

- $$\mathcal L\{f(t-a)u(t-a)\}=e^{-as}F(s)$$
- $$F_{per}(s)=\frac{\int_0^T f(t)e^{-st}\,dt}{1-e^{-sT}}$$

### 结论/核验状态

### 易错点

- 延迟只乘指数却不平移函数
- 周期公式分子积分区间错误
- 非零初值与传递函数混用

!!! tip "我的思考：为什么这题值得收进体系"
    画波形后再写阶跃组合，通常比直接积分更稳；反变换先识别极点结构，能预判时域项的形状。

G(s)=5/(τ^2s^2+2τζs+1)，闭环极点 -2±j√12；求振荡频率、阻尼比、5%调整时间、最大超调和峰值时间。

**来源定位**

1. 先求闭环传递函数并检查闭环稳定。
