## C6.1 稳态误差的基本概念

**学习目标**：建立误差信号、偏差信号、稳态误差和误差传递函数的概念，区分输出误差与比较点误差。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 题目出现非单位反馈、扰动通道或要求某物理量的误差。 |
| 主方法 | 先定义“期望量减实际量”的物理误差，再根据方块图写该误差与输入/扰动的传递关系；最后用终值定理。 |
| 核心关系 | $e_{ss}=\lim_{t\to\infty}e(t)=\lim_{s\to0}sE(s)$，前提是 $sE(s)$ 的极点满足终值定理条件。 |
| 失效边界 | 单位反馈下比较点误差与输出误差一致；非单位反馈时不能直接套单位反馈公式。 |
| 达标证据 | 能对非单位反馈系统明确写出误差定义和误差传递函数。 |
| 标签 | 稳态误差 · 误差定义 · 终值定理 |

## C6.2 输入引起的稳态误差

**学习目标**：掌握系统型别、静态误差系数与阶跃/斜坡/加速度输入稳态误差。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 给开环传递函数和标准多项式输入，要求稳态误差或参数设计。 |
| 主方法 | 数开环原点极点确定型别；计算位置、速度、加速度误差系数；按输入类型选择公式。 |
| 核心关系 | $K_p=\lim_{s\to0}L(s)$，$K_v=\lim_{s\to0}sL(s)$，$K_a=\lim_{s\to0}s^2L(s)$。 |
| 失效边界 | 型别只描述低频积分阶次，不保证系统稳定；稳态误差公式必须建立在闭环稳定基础上。 |
| 达标证据 | 能对 0、I、II 型系统快速填写三种典型输入误差表。 |
| 标签 | 系统型别 · 静态误差系数 · 跟踪误差 |

## C6.3 干扰引起的稳态误差

**学习目标**：掌握扰动作用点不同导致的稳态误差差异，能推导扰动到输出和误差的传递函数。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 方块图中扰动在对象前、对象后或反馈通道进入，要求扰动误差。 |
| 主方法 | 采用叠加原理：令给定为零，保留扰动；从扰动注入点沿前向与反馈关系写闭环传递函数，再取稳态极限。 |
| 核心关系 | 低频高增益通常有利于抑制对象输入端扰动，但对传感器噪声和不同注入点效果不同。 |
| 失效边界 | 不能用输入误差常数直接代替扰动通道推导；扰动位置改变分子和低频阶次。 |
| 达标证据 | 能对同一系统三种扰动位置分别写误差传递函数。 |
| 标签 | 扰动误差 · 叠加原理 · 扰动通道 |

## C6.4 减小系统误差的途径

**学习目标**：理解通过提高低频增益、增加积分、复合控制、前馈和合理反馈减小误差的路径与代价。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 设计题要求减小稳态误差，同时保持稳定性和动态性能。 |
| 主方法 | 先判断误差来源和所需低频阶次；选择增益、积分、前馈或复合控制；随后重新检查稳定裕度、超调和饱和。 |
| 核心关系 | 误差改进不是只增大增益；控制器结构改变会同时影响低频精度与中高频稳定性。 |
| 失效边界 | 积分可消除某些稳态误差，但会增加相位滞后和积分饱和风险。 |
| 达标证据 | 能为一个误差指标提出至少两种方案并比较副作用。 |
| 标签 | 误差改善 · 积分控制 · 前馈 |

## C6.5 动态误差系数

**学习目标**：掌握动态误差系数展开，用于描述缓慢变化输入下的跟踪误差。

| 字段 | 内容 |
| --- | --- |
| 题目信号 | 输入不是单纯阶跃/斜坡，要求近似动态误差或误差随输入导数的关系。 |
| 主方法 | 在低频处展开误差传递函数，将 $E(s)/R(s)$ 表成 $s$ 的幂级数；反变换得到输入及其导数的线性组合。 |
| 核心关系 | $e(t)\approx C_0r(t)+C_1\dot r(t)+C_2\ddot r(t)+\cdots$。 |
| 失效边界 | 动态误差系数是低频/缓变近似；高频输入、非光滑输入或闭环不稳定时不能依赖该展开。 |
| 达标证据 | 能从一个误差传递函数求前三个动态误差系数并解释适用条件。 |
| 标签 | 动态误差系数 · 低频展开 · 跟踪 |
