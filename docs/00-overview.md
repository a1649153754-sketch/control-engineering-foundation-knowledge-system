# 体系总览

> 这套知识库把课程组织成“对象—模型—分析—评价—设计—验证”六层闭环。章节顺序沿用教材，但复习时可以按任务跨章调用。

## 一、六层闭环

| 层级 | 核心问题 | 主要章节 | 输出物 |
| --- | --- | --- | --- |
| 1. 对象 | 控制谁、给定什么、测量什么、扰动从哪里来？ | C1 | 控制任务与功能方块图 |
| 2. 模型 | 动态关系怎样用方程表达？ | C2 | 微分方程、传递函数、状态空间 |
| 3. 分析 | 系统怎样随时间和频率响应？ | C3、C4、C8 | 响应、极点、频率特性、根轨迹 |
| 4. 评价 | 是否稳定、误差多大、性能是否达标？ | C5、C6 | 稳定判据、裕度、稳态/动态误差 |
| 5. 设计 | 需要怎样改变结构和参数？ | C7、C9、C10 | 校正器、PID、非线性/数字方案 |
| 6. 验证 | 理论、软件与实验是否一致？ | C3.6、C4.9、C7.8、C10.5、C11 | 指标表、曲线、实验记录、可复现代码/VI |

## 四、掌握等级

| 等级 | 含义 | 可观察证据 |
| --- | --- | --- |
| 0 | 未识别 | 看见标题也说不清研究对象 |
| 1 | 能复述 | 能解释定义与公式，但不会独立启动 |
| 2 | 能调用 | 典型题能独立完成，边界检查不稳定 |
| 3 | 稳定掌握 | 变式中能选择方法、解释条件并自检 |
| 4 | 能迁移 | 能跨时域/频域/根轨迹或理论/实验互证 |

## 五、错误标签

| 标签 | 含义 | 常见表现 |
| --- | --- | --- |
| `MOD` | 建模错误 | 坐标、方向、物理方程、参数折算错误 |
| `ALG` | 代数运算 | 展开、因式分解、部分分式、复数计算错误 |
| `SIG` | 信号与结构 | 反馈符号、比较点、支路和作用点错误 |
| `CON` | 条件漏检 | 稳定、零初值、终值定理、近似条件未查 |
| `FREQ` | 频域读图 | 转折频率、斜率、相位、裕度读错 |
| `DYN` | 动态理解 | 极点—模态—指标关系混乱 |
| `DES` | 设计闭环 | 只算参数，不做全指标复核 |
| `NUM` | 数值/软件 | 单位、步长、频率范围、采样时间错误 |
| `EXP` | 实验 | 仪器动态、噪声、标定和可重复性遗漏 |

## 六、推荐使用顺序

1. 先读对应章节节点，完成五项检查中的前两项。
2. 查规则与公式卡，遮住结论做主动提取。
3. 做配套题时标记 `Q` 母题和错误标签。
4. 错误挂到边界卡或个人疑问节点，写最小修复动作。
5. 在 3/7/14 天重新做同类题；只有跨语境稳定才升级掌握等级。
