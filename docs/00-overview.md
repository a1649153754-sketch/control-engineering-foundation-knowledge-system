## 六、公式阅读与条件检查

- [LaTeX 公式图鉴](25-formula-atlas.md)用于看清公式结构；
- [规则与公式卡](14-formula-cards.md)用于核对触发条件和失效边界；
- [习题反哺补充库](26-exercise-supplements.md)用于把多道题的共性结论抽出来；
- 长公式在移动端可横向滚动，不再塞进狭窄表格中强行缩小。

公式调用前至少检查：系统结构、零初始条件、稳定性、阻尼类型、输入类型、频率单位和近似条件。

## 七、掌握等级

| 等级 | 含义 | 可观察证据 |
| --- | --- | --- |
| 0 | 未识别 | 看见标题也说不清研究对象 |
| 1 | 能复述 | 能解释定义与公式，但不会独立启动 |
| 2 | 能调用 | 典型题能独立完成，边界检查不稳定 |
| 3 | 稳定掌握 | 变式中能选择方法、解释条件并自检 |
| 4 | 能迁移 | 能跨时域/频域/根轨迹或理论/实验互证 |

## 八、错误标签

| 标签 | 含义 | 常见表现 |
| --- | --- | --- |
| `MODEL` | 模型与端口 | 坐标、方向、物理方程、输入输出或初值错误 |
| `STRUCT` | 信号与结构 | 反馈符号、比较点、支路和作用点错误 |
| `COND` | 条件漏检 | 稳定、零初值、终值定理、近似条件未查 |
| `ALG` | 运算 | 展开、因式分解、部分分式、复数和单位错误 |
| `INTERP` | 解释 | 极点—模态—指标、曲线与物理含义混乱 |
| `VERIFY` | 验证 | 没做量纲、极限、终值、稳定或软件交叉检查 |

旧版 `MOD/SIG/CON/FREQ/DYN/DES/NUM/EXP` 标签仍可用于细分；逐题解析默认使用上表六类总标签，便于跨章统计。

## 九、推荐使用顺序

1. 先读对应 `C` 节点，明确研究对象、条件和输出物。
2. 去公式图鉴看结构，再回 `K` 卡确认边界。
3. 独立做原题，先写 `Q` 母题和第一动作，不先看解答。
4. 卡住时只查对应 `EX` 卡的断点，再回原习题解核对图形和参数。
5. 用自己的符号完成二稿，记录错误标签和最小修复动作。
6. 在 3/7/14 天重做；能换方法或用软件互证后再升级掌握等级。
