## 二、MATLAB 任务矩阵

| 任务 | 典型命令 | 最小复核 |
| --- | --- | --- |
| 建立模型 | `tf`、`zpk`、`ss` | 阶数、直流增益、极点、采样时间 |
| 结构连接 | `series`、`parallel`、`feedback` | 反馈符号和手算简化 |
| 时域响应 | `step`、`impulse`、`lsim`、`stepinfo` | 初值、终值、峰值和仿真步长 |
| 频域响应 | `bode`、`nyquist`、`nichols`、`freqresp` | 低高频极限、转折频率、单位 |
| 稳定裕度 | `margin`、`allmargin`、`pole`、`isstable` | 开环极点、多次交叉、近相消 |
| 根轨迹 | `rlocus`、`rlocfind` | 起终点、实轴段、渐近线 |
| 模型变换 | `residue`、`minreal`、`c2d`、`d2c` | 初值约定、相消风险、离散化方法 |
| 非线性仿真 | ODE 求解器、事件函数、相图 | 多初值、步长收敛、分段边界 |

## 三、最小脚本骨架

```matlab
% 1) 模型
s = tf('s');
G = 1/(s*(0.5*s+1));

% 2) 基线分析
T0 = feedback(G,1);
p0 = pole(T0);
info0 = stepinfo(T0);
[gm,pm,wcg,wcp] = margin(G);

% 3) 控制器/校正器
C = 1;              % 替换为设计结果
L = C*G;
T = feedback(L,1);

% 4) 全指标输出
disp(pole(T));
disp(stepinfo(T));
margin(L);
grid on;
```

脚本中的模型只是演示结构，不对应教材某道题。实际使用时必须注明对象、单位和反馈形式。

## 四、软件结果检查顺序

1. `pole`：稳定性与主要时间尺度。
2. `dcgain` 或低频极限：稳态值与误差。
3. `step/impulse`：初值、终值、超调和衰减趋势。
4. `bode/margin`：转折频率、斜率和裕度。
5. 参数扫描：临界值是否与 Routh/Nyquist/根轨迹一致。
