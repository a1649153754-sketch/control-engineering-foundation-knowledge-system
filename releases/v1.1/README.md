# v1.1.0

本版本把 v1.0.0 的“章节知识框架”推进为“公式可读 + 逐题可查 + 由题反哺”的完整学习闭环。

## 规模

- 11 章、77 个稳定节点
- 385 个三级检查项
- 231 张规则与公式卡
- 1 套 MathJax LaTeX 公式图鉴
- 配套习题解第 1—10 章 193 / 193 道逐题解析
- 78 类母题、44 张边界卡、16 条决策树
- 20 个实验/软件任务、12 条个人疑问挂接

## 逐题解析字段

每道题均包含：原创题意摘要、对应知识点、母题、来源页、解析路线、关键公式、结果校验、易错点和“由本题补入知识库”。

## 版权边界

二进制来源教材与习题解、扫描页、完整题面和逐字解答均不包含在发布物中。
